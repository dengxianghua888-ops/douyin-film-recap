# 测量录制时间偏移

通过 [原子执行器](../../runtime/editing_runtime.py) 调用 `sync-offset-measure`，字段见 [多机位合同](../../contracts/multicam-contract.md)。明确 reference、follower、窗口/标记及接受阈值；所有文件先登记原始字节哈希。

约定 `session_time = source_time + offset_seconds`。正偏移表示跟随素材开始得较晚；参考素材的源时间零为会话零。输出候选偏移、各窗口证据、离散程度、覆盖跨度及问题，不修改素材。

已有出版方/设备共同时间轴时可用 declared-clock 导入明确零点、覆盖区间与声明文件。结果为 DECLARED，未做测量；未知误差保留 null。禁止用假标记把时钟声明伪装成观察。编译须显式允许声明时钟，成片仍需物理同步复核。

波形法需要声明的 NumPy 环境及双方音频，不根据字幕相似度声称物理同步。标记法只计算调用方提供的对应关系，至少三个有时间跨度的标记，证据文件保存复核依据。两种方法均不能独自确认同一录制事件或人物身份。

不同麦克风使原始波形相关性低时，可显式选择 log-rms-envelope 和窗口/步长，对能量变化做粗定位。搜索步长不是准确度；包络一致不能替代口型或声学细同步，不静默切换方法或改阈值。

`SUCCEEDED` 表示测量操作完成；`REVIEW_NEEDED` 不能作为自动应用许可。即使 `CONSISTENT`，也只在所测范围、所用阈值和恒定偏移假设下成立。周期音乐、共享片头、静音、窗边峰值或时钟漂移需换证据/分段测量，不隐式拉伸声音。
