# 比喻后返回

版本0.1.0；知识图文。已设计，效果未独立验证。

执行边界：所需素材：概念、相似关系、不适用点。已有可控图示、真实图像或合格候选可直接进入评审和剪辑；缺视觉资产时由当前 Agent 核图形制作或生成能力，做不到则只交脚本/分镜和已有素材部分并记录缺项。核验：能指出比喻的适用边界；示意不能冒充事实，候选可用不等于效果通过。
