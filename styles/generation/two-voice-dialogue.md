# 双声部对话

版本0.1.0；数字人表达。已设计，效果未独立验证。

执行边界：所需素材：两身份与真实可辨的论点。已有授权数字人候选可进入评审和剪辑；需新合成时由当前 Agent 核数字人、声音及口型能力与授权，当前无合格候选且能力与授权可用时，由 Agent 生成候选并评审；能力不可用或生成后仍无合格候选时，只交脚本/分镜及已有素材部分并记录缺项。实看实听：每句归属正确且非假专家背书；身份、语音归属和口型不因任务成功而默认合格。

## 组合与来源

图文与声音分工；镜头目的和阅读负担；实际可用资产与生成规格；连续性锚点；局部保护与修改范围。符合事实或虚构身份，所需执行能力真实可用。不把模型成功当效果，不把静图运镜冒充生成主体运动。原创机制综合，见[来源融合](../../workflows/raven-script-generation/references/source-fusion.md)。构造例不是生成结果，实际证据单列catalog。
