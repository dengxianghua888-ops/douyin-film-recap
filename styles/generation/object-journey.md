# 物件旅程

版本0.1.0；虚构短片。已设计，效果未独立验证。

执行边界：所需素材：明确物件锚点及位置状态。已有合格候选可进入评审和剪辑；需新生成时由当前 Agent 核实际图像/视频能力、授权、预算和输出身份，当前无合格候选且能力与授权可用时，由 Agent 生成候选并评审；能力不可用或生成后仍无合格候选时，只交脚本/分镜及已有素材部分并记录缺项。逐镜核验：观众追得上物件状态变化；模型返回成功不等于连续性或效果通过。

## fit

一个物件连接多个空间

## question

物件状态怎样推进故事

## selection

明确物件锚点及位置状态

## sequence

出现→流转→新用途

## audio

音效强调实际动作，不替代因果

## rhythm

转交和落点不切断

## visual

检查数量、形状和持有关系

## anti

物件每镜变样却不说明

## example

构造例：红色信封在不同房间被传递

## nearest

与角色叙事不同，物件是持续主体

## effect_check

观众追得上物件状态变化

## 组合与来源

图文与声音分工；镜头目的和阅读负担；实际可用资产与生成规格；连续性锚点；局部保护与修改范围。符合事实或虚构身份，所需执行能力真实可用。不把模型成功当效果，不把静图运镜冒充生成主体运动。原创机制综合，见[来源融合](../../workflows/raven-script-generation/references/source-fusion.md)。构造例不是生成结果，实际证据单列catalog。
