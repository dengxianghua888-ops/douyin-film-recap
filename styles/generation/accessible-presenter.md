# 清楚易读讲述

版本0.1.0；数字人表达。已设计，效果未独立验证。

执行边界：所需素材：简明稿、清晰字幕、稳定构图。已有授权数字人候选可进入评审和剪辑；需新合成时由当前 Agent 核数字人、声音及口型能力与授权，当前无合格候选且能力与授权可用时，由 Agent 生成候选并评审；能力不可用或生成后仍无合格候选时，只交脚本/分镜及已有素材部分并记录缺项。实看实听：可读可听，信息没有因简化失真；身份、语音归属和口型不因任务成功而默认合格。
