# 新闻／纪录片／人物风格索引

按作品要回答的问题选择机制；可以组合主辅机制，事实与人物语境优先。数量不设上限，当前所有卡效果未独立验证。

## 新闻

| 风格 | 适用 | 核心问题 |
|---|---|---|
| [事实简报](fact-brief.md) | 事件身份与核心事实有可靠来源 | 发生了什么，目前知道多少？ |
| [事件时间线](chronology.md) | 各节点有可追溯时间 | 变化按什么先后发生？ |
| [核验路径](verification-path.md) | 存在待核问题与实际查证记录 | 这条信息怎样得到确认？ |
| [说法与证据](claim-evidence.md) | 有可准确引用的说法及相关证据 | 这项说法有多大支持？ |
| [已知与未决](known-unknown.md) | 正在变化且证据不完整 | 哪些已经知道，哪些还不能下结论？ |
| [公开更正](correction.md) | 旧输出存在具体可确认错误 | 哪里错了，正确说法是什么？ |
| [条件与例外](conditions.md) | 政策或措施有明确适用条件 | 这件事对谁在什么条件下成立？ |

| [地方视角](local-angle.md) | 地方影响与人群有真实素材 | 同一事件在这里意味着什么？ |
| [后续影响](consequences.md) | 有事件后的可观察变化 | 事情发生后改变了什么？ |
| [来源分歧](source-comparison.md) | 多个真正独立的来源有实质差异 | 哪些信息一致，分歧在哪里？ |
| [机制解释](mechanism-explainer.md) | 规则或过程有可信资料 | 为什么会这样运作？ |
| [进展快照](ongoing-snapshot.md) | 事件持续中且有明确截至时点 | 截至现在进展到哪一步？ |

| [现场观察札记](field-dispatch.md) | 现场身份与记录时点明确 | 在这个位置可以观察到什么？ |
