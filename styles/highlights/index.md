# 事件高光风格库

30个初始机制，体育/游戏/直播各10种，不设总数上限。风格按素材与目标选取；探索卡均未验证，不以命名或数量作为效果。需要变速/跟踪/游戏数据接口时先核对实际能力，不假装存在。

| 风格 | 领域 | 适用 | 差别 |
|---|---|---|---|
| [完整回合](complete-possession.md) | 体育 | 可见进攻发起和结束 | 区别于瞬间回放，以完整事件为单位 |
| [防守救险](defensive-save.md) | 体育 | 有阻断、扑救或防守协作 | 区别于进攻回合，价值来自风险消除 |
| [配合链条](team-combination.md) | 体育 | 传跑、掩护或协作形成机会 | 区别于完整回合，突出多人协作机制 |
| [动作拆解](technique-breakdown.md) | 体育 | 动作有可观察的技术阶段 | 区别于战术空间，以单个动作机制为中心 |
| [瞬间回放](moment-replay.md) | 体育 | 已有可独立辨认的关键动作 | 区别于动作拆解，可不讲原理，目标是看清瞬间 |
| [转折回顾](turning-point.md) | 体育 | 比赛有可核对的前后局势 | 区别于完整回合，必须比较前后局势 |
| [攻防互答](rivalry-exchange.md) | 体育 | 双方有连续可比较的回应 | 区别于转折回顾，重策略互动不必有胜负翻转 |
| [训练变化](training-progress.md) | 体育 | 同类动作多次尝试且条件可比 | 区别于动作拆解，中心是可见变化过程 |
| [弱势应对](underdog-context.md) | 体育 | 有可证实的条件差异而非想象人设 | 区别于转折回顾，关注约束下的选择 |
| [赛事章节](match-chapters.md) | 体育 | 多个真实事件需要压缩成可回看的记录 | 区别于单回合，建立全局过程和导航 |
| [交战来回](game-engage-disengage.md) | 游戏 | 有发起、资源交换和撤离/结束 | 区别于击杀集锦，事件可以零击杀结束 |
| [残局判断](clutch-decision.md) | 游戏 | 少人/资源不足时有可见选择 | 区别于交战来回，聚焦信息受限下的个人选择 |
| [资源交换](objective-trade.md) | 游戏 | 团队让出一处以换取另一处目标 | 区别于残局判断，组织轴是团队资源账 |
| [连招可读](combo-readability.md) | 游戏 | 动作连锁能从素材中辨认 | 区别于瞬间回放，重点是动作依赖关系 |
| [局势翻转](comeback-arc.md) | 游戏 | 有可核对的劣势和后续变化 | 区别于单场交战，以多事件的变化链为主 |
| [失误复盘](learning-from-failure.md) | 游戏 | 失误原因可从现场信息解释 | 区别于训练变化，以一次失误的可解释性为中心 |
| [安静策略](quiet-strategy.md) | 游戏 | 慢节奏布局、运营或潜行有关键变化 | 区别于残局判断，关注较长时间的布局 |
| [沟通协作](team-communication.md) | 游戏 | 真实语音与协同行动能对应 | 区别于资源交换，突出交流如何作用于行动 |
| [挑战尝试](speedrun-attempt.md) | 游戏 | 有明确挑战规则和可见起终点 | 区别于比赛回顾，核心是挑战规则与一次尝试 |
| [探索发现](world-discovery.md) | 游戏 | 玩家探索产生新地点、机制或意外 | 区别于安静策略，回报是认识变化而非胜率 |
| [铺垫兑现](live-setup-payoff.md) | 直播 | 笑点/惊喜有具体前提和回应 | 区别于连续回调，只完成一个独立表达单元 |
| [连续回调](callback-thread.md) | 直播 | 同一梗跨时间多次演变 | 区别于铺垫兑现，以多次变化积累效果 |
| [演示证据](live-demo-evidence.md) | 直播 | 主播实际展示产品、操作或实验 | 区别于软件教程，不默认整理成完整教学课程 |
| [观众问答](chat-response.md) | 直播 | 有真实可用聊天记录及同期回应 | 区别于专题问答，额外要求平台聊天时钟校准 |
| [现场补救](live-recovery.md) | 直播 | 临场故障、失误后有实际应对 | 区别于失误复盘，侧重现场应对过程 |
| [人物瞬间](live-personality.md) | 直播 | 人物表达通过具体选择或反应体现 | 区别于笑点结构，可以安静且无包袱 |
| [话题精华](live-topic-digest.md) | 直播 | 多段讨论需要有主题地浓缩 | 区别于会议提炼，不追求团队决议或行动承诺 |
| [表演段落](live-performance.md) | 直播 | 音乐、舞蹈或技能表演有完整段落 | 区别于人物瞬间，以表演结构为组织单位 |
| [直播挑战](live-challenge.md) | 直播 | 有明确挑战目标和实际尝试 | 区别于游戏速通，不限游戏但同样保护规则 |
| [一场直播的变化](live-session-arc.md) | 直播 | 长场次有可观察的目标与状态变化 | 区别于话题精华，以整场变化而非单主题论述为轴 |
