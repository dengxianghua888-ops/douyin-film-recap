# 访谈与多机位风格库

24 个初始方向，不设数量上限。全部为已设计、效果未验证；以实际选段、观点结构、声画关系差异决定是否保留，不把文件数量当效果。同期反应真实性和观点归属不能因风格而降低要求。

| 风格 | 适用 | 主要区别 |
|---|---|---|
| [完整对话](complete-conversation.md) | 问答自然推进且观众重视完整语境 | 相较观点浓缩优先完整话轮而非最短结论 |
| [论点与证据](thesis-evidence.md) | 嘉宾有明确判断且提供例证 | 相较短答卡以证据链为最小单位，可以跨多个话轮 |
| [观点交锋](idea-duel.md) | 双方确有实质分歧和回应 | 相较分歧保留更强调回合动态，不能牺牲立场公平 |
| [人物内省](reflective-portrait.md) | 访谈有选择、犹豫和价值变化 | 相较口述历史重当下自我理解而非外部事件编年 |
| [口述历史](oral-history.md) | 参与者回忆长期事件，时间与记忆可靠性重要 | 相较亲历证言覆盖更长历史过程，记忆与资料层次更显式 |
| [亲历证言](experiential-witness.md) | 受访者讲述具体事件的自身经历 | 相较口述历史聚焦单次事件的证据边界 |
| [追问求证](investigation-followup.md) | 问题需要澄清且素材有实际追问 | 相较观点交锋重事实可检验性而非立场辩论 |
| [问答带学](socratic-learning.md) | 主持人从初学者疑问推进概念 | 相较技术深谈为初学者构建概念阶梯 |
| [实战案例复盘](practitioner-case.md) | 嘉宾有具体项目、选择及结果 | 相较论点证据关注一次行动链而非抽象主张 |
| [专业深谈](technical-deep-dive.md) | 受众有基础，需要机制、参数和权衡 | 相较问答带学默认受众具备基础，允许较长推导 |
| [圆桌观点地图](roundtable-map.md) | 多人围绕一个主题提出不同观察 | 相较主题拼接保留同场互动及回应关系 |
| [共识形成](consensus-evolution.md) | 讨论实际产生了方案修正或共同决定 | 相较实战复盘重现场共同决策形成过程 |
| [保留分歧](disagreement-preserved.md) | 对话结束仍有不一致，不能强求统一 | 相较观点交锋更重未解决边界而非回合张力 |
| [群聊现场感](collective-energy.md) | 熟人群谈有交叉、接梗与共同记忆 | 相较圆桌地图重共同叙述的互动感，信息地图可简化 |
| [留白对谈](contemplative-dialogue.md) | 谈话包含沉思、情绪加工和慢节奏交流 | 相较人物内省重两人共同思考的过程，未必有传记线 |
| [对谈喜剧节拍](comic-timing.md) | 源对话本身有包袱、误会和回应 | 相较群聊现场感每个笑点有完整结构，不只是多人热闹 |
| [倾听中的关系](relational-listening.md) | 对话价值在两人理解、误解和修复 | 相较留白对谈重点是关系转折而非思考速度 |
| [实物引导访谈](artifact-led.md) | 受访者展示作品、旧物或资料并讲述 | 相较过程示范物件用于证据与回忆，不要求完整操作步骤 |
| [边做边谈](process-demonstration.md) | 受访者在制作、操作或演示中解释 | 相较实物访谈强调动态方法和动作结果的连续性 |
| [在场访谈](place-immersive.md) | 谈话发生在有意义的地点且现场影响内容 | 相较人物内省环境是叙述条件，不只是装饰空镜 |
| [经历到经验](chronology-to-lesson.md) | 嘉宾经历多个阶段且有后续反思 | 相较实战案例可跨多个经历阶段，经验形成是主线 |
| [单问题短答](short-answer-card.md) | 一个回答可独立理解且有明确受众问题 | 相较论点证据面向一个独立短问题，不组织多轮论证 |
| [主题并置](multi-viewpoint-theme.md) | 多个问题或多次访谈围绕同一主题 | 相较圆桌地图允许跨会话，必须明确不是现场互动 |
| [决策简报](executive-brief.md) | 长讨论需供决策者快速了解选项和未决项 | 相较共识形成聚焦结果供决策使用，可不展开全部互动过程 |

主风格决定结构，局部手法可以借用。人物内省可借倾听镜头；短答卡可借论点证据，但时长不足时不能删除必要限定。留白对谈与决策简报目标冲突时以用户目的选主风格，不能两套配额同时套用。
