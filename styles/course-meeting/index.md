# 课程与会议风格库

28 个初始机制（会议14、课程14），不设总数上限。全部为待验证方法；先看素材和目标选择，不能只看名字组合。每张卡必须在同素材对照中表现出不同选段、结构或声画选择。探索卡不自动进入已验证默认推荐。

| 风格 | 适用 | 区别 |
|---|---|---|
| [分歧脉络](disagreement-thread.md) | 讨论有真实分歧且没有简单胜负 | 不同于决策纪要，它以未收敛的分歧为可用结果 |
| [决策来路](decision-trace.md) | 有明确决议且讨论提供决策理由 | 区别于分歧脉络，必须有源中明确收束 |
| [行动交接](action-handoff.md) | 会议确有可追踪的承诺或分工 | 区别于决策来路，围绕执行责任而非方案论证 |
| [议题速览](issue-brief.md) | 长会议包含多个可分开的议题 | 区别于行动交接，覆盖议题状态并允许没有任务 |
| [约束先行](constraint-first.md) | 方案被预算、时限、法规或技术条件约束 | 不同于决策来路，可在尚无决定时解释限制 |
| [提案演变](proposal-evolution.md) | 方案在讨论中多次修改 | 区别于决策来路，重点是内容变化而非批准结果 |
| [假设核对](assumption-audit.md) | 讨论依赖未验证的用户、市场或技术假设 | 区别于分歧脉络，聚焦可验证性而非立场 |
| [风险与阻塞](risk-register.md) | 有失败条件、依赖或风险处置讨论 | 区别于行动交接，中心是条件和失效路径 |
| [备选方案对照](options-comparison.md) | 讨论多个同目标的方案 | 区别于约束先行，强调横向可比而不先排序 |
| [客户原话](customer-voice.md) | 用户研究会或客户反馈讨论需要保护表达 | 区别于访谈人物纪实，重点是研究证据与解释边界 |
| [复盘闭环](retrospective-loop.md) | 有目标、实际结果和原因讨论 | 区别于风险与阻塞，围绕已经发生的结果学习 |
| [角色视角](role-perspectives.md) | 不同角色关注点导致沟通错位 | 区别于分歧脉络，组织轴是目标视角而非争论轮次 |
| [未决问题清单](open-question-ledger.md) | 讨论没有足够证据形成决定 | 区别于议题速览，以信息缺口作为组织单位 |
| [专题问答](expert-qa.md) | 分享会中提问和回答具有独立价值 | 区别于行动回顾，以解释价值而非任务承诺为目标 |
| [概念阶梯](concept-ladder.md) | 零基础观众需要逐步建立概念 | 区别于速查复习，为首次学习建立依赖链 |
| [例题带学](worked-example.md) | 有完整问题、步骤和检验 | 区别于概念阶梯，以一个完整实例作为主线 |
| [误区纠偏](misconception-repair.md) | 素材明确展示错误理解及纠正依据 | 区别于边界条件，以已有误解的修复为目标 |
| [推导证明](proof-chain.md) | 理论、数学或机制说明重逻辑链 | 区别于例题带学，中心是一般命题而非单题答案 |
| [案例解剖](case-autopsy.md) | 实例有情境、选择和结果 | 区别于复盘闭环，面向教学迁移而非团队交接 |
| [对照辨析](contrast-pair.md) | 相近概念或方法容易混淆 | 区别于备选方案对照，以概念边界教学为目标 |
| [问题驱动探索](question-led-discovery.md) | 素材有真实提问、尝试和发现 | 区别于误区纠偏，不预设一种常见错误作为中心 |
| [实验与演示](lab-demonstration.md) | 物理、技能或操作课有可见过程 | 区别于软件教程，覆盖物理现象和实验条件 |
| [边界条件](boundary-conditions.md) | 原则容易被过度泛化 | 区别于误区纠偏，不要求先有错误，只防止外推 |
| [练习停顿](practice-pause.md) | 课程有可独立完成的题或观察任务 | 区别于例题带学，主动尝试是内容结构的一部分 |
| [速查复习](retrieval-review.md) | 观众已学过，需要回忆和定位 | 区别于概念阶梯，以已知为前提而非建立基础 |
| [迁移桥梁](transfer-bridge.md) | 素材给出原例与不同情境下的应用 | 区别于案例解剖，至少比较两个不同情境 |
| [流程地图](process-map.md) | 技能流程有分支、判断和返回路径 | 区别于概念阶梯，以可执行决策路径为中心 |
| [知识演进](historical-development.md) | 课程解释理论或技术如何随问题演变 | 区别于推导证明，重点是问题与方法的历史变化 |
