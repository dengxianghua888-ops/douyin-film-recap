# 商品／体验／品牌风格索引

根据作品要回答的问题选择主要机制。数量不设上限；同义改名、换字幕颜色或画幅不算新风格。所有卡当前已设计，实际效果未验证。

## 产品

| 风格 | 适用 | 核心问题 |
|---|---|---|
| [操作本身作证](action-proof.md) | 有连续操作和实际结果 | 到底怎样完成这件事？ |
| [先看可见结果](result-first.md) | 结果可以快速辨认且有过程可回溯 | 这个状态是怎样得到的？ |

| [两种使用状态](state-choice.md) | 同一对象有不同形态或用法 | 什么状态适合什么动作？ |
| [功能落到动作](feature-to-action.md) | 有规格和实际对应动作 | 这一功能在使用时在哪里？ |
| [细节回到整体](detail-and-whole.md) | 真实细节与整体可配对 | 细节怎样影响实际使用？ |
| [先讲适用条件](condition-led.md) | 效果依赖场景且条件影响决策 | 在什么条件下值得考虑？ |
| [条件明确的比较](honest-comparison.md) | 有可比条件与可追溯两组素材 | 差异究竟来自哪里？ |
| [限制先说清](limitation-first.md) | 有真实不适用或失效情况 | 谁可能不该选它？ |
| [从开箱到使用](unbox-to-use.md) | 包装内容和首次使用有实拍 | 拿到手后要经历哪些步骤？ |
| [真实上手门槛](setup-reality.md) | 安装/设置过程和完成条件有记录 | 开始用之前要付出什么？ |
| [用完之后](care-after-use.md) | 清理、维护或收纳有真实素材 | 便利是否延续到使用之后？ |
| [器物与声音](object-sound.md) | 原声能体现真实可听动作 | 这个物件怎样被触碰和使用？ |
| [测量说清楚](measurement-explained.md) | 有可靠量具、方法和完整记录 | 这个数字怎样得来？ |

| [只说一个有据卖点](small-specific-claim.md) | 短时长只能讲清一个可证事实 | 哪一个事实最值得被看见？ |
| [另一种用法与边界](alternative-use-boundary.md) | 有真实替代用途且不违反已知使用限制 | 这个用法在什么范围成立？ |
| [实际包含什么](packing-contents.md) | 包装内含和选配信息可核对 | 买到的是哪些东西？ |

| [只看手和物](hands-only-use.md) | 已有手部使用实拍且无需见证口播 | 动作能否代替讲解？ |
| [克制的个人推荐](quiet-recommendation.md) | 真实使用者愿意推荐且理由具体 | 他愿意推荐给哪一种人？ |
| [失败也保留语境](failure-with-context.md) | 真实试用未达预期且条件有记录 | 这次没成功能说明多少？ |
