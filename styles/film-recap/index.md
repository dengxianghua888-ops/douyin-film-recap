# 影视解说风格索引

当前 26 张为第一轮原创综合，不是数量上限，也不是已验证效果数。按创作目标与源证据选择，所有卡均为 authored-unvalidated。

先定位家族，再读具体卡；不要一次加载所有卡。卡不匹配时可修改或补研扩展，不强行套用。

[当前作品与样片记录](../../docs/evidence-scope.md)包含苹果小事件、观众知情差与喜剧反应三个可编辑候选；[内容复核](../../docs/evidence-scope.md)说明源片时间基、风格差异和未证实项。两版陷阱来自同一场景，分别偏重准备过程和反应；均仍含观众提前看见危险的机制，不能将其中一版当作受限视角。

旧小事件与早段知情差试剪已被否决为效果证据，旧产物保留。新三版只有技术回读与抽样内容／画面证据，完整看听、独立辨识和宿主验收未完成；全部风格继续保持 authored-unvalidated。

| 家族 | 风格 | 核心观众问题 |
|---|---|---|
| 结构与信息 | [因果主线](causal-spine.md) | 他为了什么采取行动，这个行动如何招致下一步后果？ |
| 结构与信息 | [后果追因](result-backtrack.md) | 这个已发生的后果，究竟由哪次选择开始？ |
| 结构与信息 | [程序与证据推进](procedural-investigation.md) | 每条证据改变了哪一步判断，下一步为何合理？ |
| 结构与信息 | [双线交叉](parallel-crossroads.md) | 两个人的行动会在什么地方相互改变？ |
| 认知与悬念 | [线索递进悬疑](clue-suspense.md) | 观众此刻能合理怀疑什么，下一条证据如何改变怀疑？ |
| 认知与悬念 | [受限视角](restricted-pov.md) | 只跟随这个人物，我们能知道和误以为什么？ |
| 认知与悬念 | [不可靠叙述对照](unreliable-accounts.md) | 同一事件的讲述哪里冲突，哪些事实仍不能确定？ |
| 认知与悬念 | [限时任务](deadline-tension.md) | 剩余时间或资源如何改变人物选择？ |
| 人物与关系 | [关系渐变](relationship-drift.md) | 两个人何时开始不再像从前那样对待彼此？ |
| 人物与关系 | [人物选择与弧线](character-arc.md) | 他最初怎样选择，付出什么后终于改变或拒绝改变？ |
| 人物与关系 | [道德两难](moral-dilemma.md) | 无论怎么选会伤害谁，人物为何仍要作出这次决定？ |
| 人物与关系 | [表演与沉默](performance-silence.md) | 人物在哪一瞬间改变了内在状态，而语言没有说出来？ |
| 人物与关系 | [群像与关系网](ensemble-network.md) | 同一事件如何改变不同人的立场和联盟？ |
| 人物与关系 | [日常观察与生活质地](ordinary-life.md) | 这个人的生活如何在细小重复中显出变化？ |
| 声音与场面 | [原声对峙](original-confrontation.md) | 谁在这轮对话中改变了局势，转向发生在哪里？ |
| 声音与场面 | [空间清楚的动作推进](spatial-action.md) | 目标在哪里、障碍在哪里、这次动作如何改变距离或优势？ |
| 声音与场面 | [喜剧铺垫与反应](comic-reaction.md) | 观众形成了什么预期，何时被改变，谁的反应完成笑点？ |
| 声音与场面 | [感官与氛围推进](sensory-atmosphere.md) | 观众从怎样的身体感受进入，又被带向怎样的状态？ |
| 主题与形式 | [意象回声](motif-echo.md) | 同一个东西再次出现时，观众为什么会读出不同含义？ |
| 主题与形式 | [观点与反证](contrast-argument.md) | 这个观点能解释什么，又在哪些地方必须收窄？ |
| 主题与形式 | [背景与时代语境](historical-context.md) | 哪些背景是理解人物处境必须知道的，哪些只是知识旁枝？ |
| 主题与形式 | [单场景细读](scene-close-reading.md) | 这个场面通过哪些具体声画安排完成变化？ |
| 系列与篇幅 | [连续剧集承接](serial-bridge.md) | 本集回答了哪个旧问题，又真实打开了哪个新问题？ |
| 系列与篇幅 | [短时长完整故事](micro-complete.md) | 在有限时间里，哪一个变化值得被完整经历？ |
| 认知与悬念 | [观众知情差](dramatic-irony.md) | 观众已知的事实何时被人物发现？ |
| 时间与认知 | [复演中的改口](replayed-choice.md) | 同一情境再次出现时，哪一次回应真正发生了变化？ |

各卡应与最近邻做同素材对照；变更选段、信息顺序、声音所有权和留白时留证据。补研与组合规则见 [风格组合](../../workflows/raven-film-recap/references/style-composition.md)。
