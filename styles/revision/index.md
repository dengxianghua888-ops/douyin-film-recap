# 局部修改策略与风格接续库

14 个初始机制，不设上限。它们是局部表达处理方式，继承现有影视/口播/软件场景风格；不是强制把所有作品换成14套模板。全部 authored-unvalidated。

| 策略 | 适用 | 区别 |
|---|---|---|
| [忠实修补](faithful-repair.md) | 已有作品方向成立，用户指出局部错误或不自然 | 与接点连贯相比不限声画接点；与风格统一相比不主动整饰 |
| [问题前置](question-first.md) | 已有开头铺垫较长，观众不知道为何继续看 | 与成果预览不同不先给出结果，张力来自未解决的问题 |
| [成果预览](result-preview.md) | 允许先看效果，现有教程或演示开头缺目标感 | 与问题前置相比给出承诺的形状，而非悬置答案 |
| [因果补桥](causal-bridge.md) | 局部跳剪使人物行为或操作步骤难以理解 | 与回报补足相比修前提；与论证收紧相比可能增加时长 |
| [表演呼吸](performance-breath.md) | 用户觉得太急，情绪由动作、反应或停顿承载 | 与疏密节奏相比核心是特定表演信息，不是整体速度曲线 |
| [论证收紧](argument-tighten.md) | 观点成立但例子重复、铺垫过多 | 与忠实修补相比可压缩结构，但不改观点强度 |
| [证据澄清](evidence-clarity.md) | 结论出现但支持它的画面、数据或操作结果难以看清 | 与因果补桥相比补证明强度，而非补事件前提 |
| [少说多看](less-narration.md) | 旁白复述画面或掩盖原声 | 与表演呼吸相比主改声音信息分工，画面时间可以完全不动 |
| [疏密节奏](density-contrast.md) | 局部均匀快或均匀慢，缺少事件重心 | 与表演呼吸相比允许同时压一处、放一处，主轴是段落重心 |
| [温和入场](gentle-entry.md) | 开头过于强推、夸张或判断先行 | 与问题前置相比保留开放感，不追求强悬念压力 |
| [局部风格接续](local-tone-match.md) | 新补段与原作品声音、信息密度或镜头语法冲突 | 与局部融合相比目标是新段的表达一致性，不涉及跨候选选择 |
| [回报补足](payoff-repair.md) | 片段提出问题或开始动作，却在结果前结束 | 与因果补桥相比补后果，不是补前提 |
| [接点连贯](continuity-repair.md) | 剪点出现残字、动作断裂或空间跳跃 | 与忠实修补相比限定在声音/动作/空间连续性问题 |
| [局部融合](selective-blend.md) | 用户喜欢另一候选的一部分，但不想失去当前修改 | 与局部风格接续相比核心是跨版本部分采用及最新状态保护 |

组合先选择问题机制，再借用节奏/声音策略；只处理用户允许的局部。先收紧论证又删必要证据、先做少说多看又添加重复旁白等冲突须显式解决。更多内容风格按需回原场景索引加载。
