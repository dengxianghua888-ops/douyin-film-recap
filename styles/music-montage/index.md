# 音乐混剪风格索引

先确定作品的声画关系，再选主要机制与辅机制。数量不设上限；所有卡当前已设计、效果未独立验证。

## 节奏

| 风格 | 适用 | 创作问题 |
|---|---|---|
| [稀疏脉冲](sparse-pulse.md) | 可确认少量音乐锚点且镜头可停留 | 怎样只响应有分量的音乐点？ |
| [乐句长镜](phrase-hold.md) | 乐句或较宽声段可辨且镜头内容足够 | 让画面怎样随一口音乐呼吸？ |
| [准备与落点](anticipation-hit.md) | 真实动作准备/接触/余势完整 | 如何让期待先到、动作落在音乐点？ |
| [在余势里切](cut-on-release.md) | 动作或音乐有可辨收束 | 落点之后何时换镜最舒服？ |
| [切分回应](syncopated-reply.md) | 实际切分关系或明确非正拍点可用 | 画面如何回应偏离主拍的声音？ |
| [反节奏](offbeat-counterpoint.md) | 声画都能独立成立且用户要张力 | 不跟音乐切时怎样仍保持关系？ |
| [密度起伏](density-wave.md) | 素材可支持稀密变化 | 怎样形成聚集与释放？ |
| [倍拍感](double-time-perception.md) | 音乐稳定且可确认基础脉冲 | 怎样增加视觉速度而不改音乐？ |
| [半拍重量](half-time-weight.md) | 素材适合长持且音乐仍有流动 | 怎样让快音乐显得更沉着？ |
| [停顿再启动](stop-and-resume.md) | 音乐或已授权音编存在有效停顿 | 如何让停下也成为节奏？ |
| [过门转场](fill-to-change.md) | 实际过门与段落变化可辨 | 怎样让过门准备下一种画面关系？ |
| [自由速度呼吸](unmetered-breath.md) | 无稳定拍网或明显rubato | 没有等拍网时怎样剪？ |
