# Vlog／旅行／活动风格索引

按作品要表达的内容选择主要机制，再按真实素材调整。不设数量上限；每张卡必须带来不同选段或声画决定。所有卡当前均已设计、效果未验证。

## 生活

| 风格 | 适用 | 创作问题 |
|---|---|---|
| [日常仪式](ordinary-ritual.md) | 反复做的一件小事有完整过程 | 熟悉动作里有什么值得停留？ |
| [一件小事](small-mission.md) | 有具体可见目标与实际尝试 | 今天想完成什么，后来怎样？ |
| [一天的质地](day-texture.md) | 一天有不同时段的真实片段 | 这一天的节奏怎样变化？ |
| [安静陪伴](quiet-company.md) | 活动平静，观看本身有价值 | 怎样让观众愿意陪这一段？ |
| [关系小动作](relationship-gesture.md) | 两人或多人有真实互动和回应 | 关系通过哪个具体动作显出来？ |
| [前后变化](before-after-context.md) | 有可比较的起点和终点 | 变化具体发生在哪里？ |
| [不圆满的一天](honest-failure.md) | 尝试失败或目标改变有真实记录 | 没完成之后发生了什么？ |
| [物件线索](object-thread.md) | 同一物件串起多个阶段 | 这个东西连接了哪些时刻？ |
| [过程手记](process-notebook.md) | 制作/学习有多个有意义步骤 | 当事人怎样慢慢摸索？ |
| [写给某人的片段](memory-letter.md) | 有真实收件对象和作者表达 | 作者想把哪些具体时刻留下？ |
| [微小发现](small-observation.md) | 短素材里有一个可见新细节 | 这一刻新发现了什么？ |
| [两种生活节奏](personal-contrast.md) | 两个有来源的状态可比较 | 不同状态的生活节奏有什么差异？ |
