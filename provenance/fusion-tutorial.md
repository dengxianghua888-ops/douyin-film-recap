## 固定版本软件的实际操作采集

新增来源 [miniPaint 采集引用](minipaint-capture-reference.json)。使用 4.14.3 / commit a79733eb803fc97084ef0ee4faa96b031e69e1c0 的上游预构建代码，在本地隔离 Chrome 中执行真实导入、缩放、撤销、重做、PNG 导出、JSON 保存、页面刷新、工程重开及再次导出。292 个文件分别核对 Git blob 与本地 SHA-256；首次取得的基线与原归档 132 份采用文件分开统计。MIT 文本随来源保留，不将完整应用复制进 Skill 执行层。

实际读取 save.js、open.js、resize.js 与菜单定义，采用“可查看图片 / 可恢复工程 / 会话撤销历史”三者分离的教学方法。原始导出和重开后导出字节一致，工程内嵌图像像素一致；两次导出确认后的异步文件大小回调异常仍保留，不宣称应用无错误。浏览器录像不含系统文件选择器和声音，原图上的尺寸文字不能作为元数据。

在同素材下，“静音跟做”保留导入与导出全链路，“试做与回退”保留状态比较和撤销/重做。剪辑省略处显式说明；不能把不同起点的任务完成时间当风格效率比较。新手理解和原生剪辑工程往返仍须独立验收，不从自动化成功推导。
