# 历史证据与源码范围

你打开的链接原先指向本地评测、历史报告或未分发的工作材料。本源码预览主动排除了这些材料，因此该链接统一转到本页；原链接的文字不是对应证据已公开的声明。

分发内容是 Skill、合同、路由、可选执行器、通用脚本和必要来源记录。未分发原视频、音频、模型、字体、个人路径、内部调度与运行历史、开发机二进制。不要把缺失材料替换成另一输入后宣称复现同一结果。

原始开发记录中的 SHA、文件列表、历史命令和通过结论保留其原有范围；它们不能认证本次重新编排的公开文档。`${LOCAL_ARCHIVE}` 只标识已移除的个人归档路径，不能直接执行。历史 provenance 覆盖表中的未分发文件并未随本仓库发布。

发布时保留 runtime 与通用脚本的源字节，文档只做个人路径处理与缺失链接显式化；新 README、接入说明和本页属于新的发布文档。运行效果请在你的目标环境重新验证，当前已知限制见[开发状态](development-status.md)。
