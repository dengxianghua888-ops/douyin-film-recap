# 剪辑技能库 · 项目介绍

## 一句话介绍

供 AI Agent 使用的通用视频剪辑技能库：从看懂素材、组织故事到修改细节，把不同场景的剪辑方法变成可复用的工作流。

## GitHub About

## 发布介绍

一段口播，重点是保住观点和自然停顿；一支教程，需要让人看清步骤；一段影视解说，则要处理人物、因果和揭示顺序。让 AI 调用剪辑工具之前，先要让它知道这次为什么这样剪。

「剪辑技能库」把这些方法整理成供 AI Agent 使用的场景工作流。你提供素材和目标，它为 Agent 提供分析、选段、编排、制作与局部修改的步骤，让“保留这段原声”“只改这一句字幕”这样的创作要求贯穿执行。

可以先用它分析素材、讨论剪辑方案，也可以结合 Agent 已接入的工具继续制作。Skill 层不指定编辑器或生成模型，方便融入自己的剪辑 Agent；库中还提供可选的本地 Python/MCP 执行器和影视解说制作子集。

从一段素材、一个明确任务开始试用：先看方案是否符合你的想法，再决定怎么剪。当前为开发预览，具体接入条件与许可范围见仓库文档。
