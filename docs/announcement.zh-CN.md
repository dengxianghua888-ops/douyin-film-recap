## 发布介绍

本次在原 `dengxianghua888-ops/douyin-film-recap` 仓库持续迭代：通用剪辑 Skill 库成为顶层，原影视解说 Skill 作为其中的场景子集。旧版 v0.2.0 与 MIT 制作流水线继续保留；通用库处于 v0.3.0-alpha.1 源码预览阶段。

做剪辑 Agent，难点不只是让它调用工具。删一句话可能改变原意，改一行字幕可能覆盖用户刚调好的位置，导出成功也不代表作品真的符合要求。

Editing Skill Library 尝试把这些问题写进执行过程：复杂 Skill 负责内容与剪辑判断，原子 Skill 约定操作边界；执行后读回作品，区分“生成了候选”“作品已采用”和“完成交付”。

这次提供 34 个原子 Skill、16 条复杂工作流和可选的本地 Python／MCP 执行入口。它面向通用剪辑 Agent：工具由 Agent 选择，模型与 Provider 也由运行层负责。你可以先读取 Skill，把已有工具接到相应操作上。

当前是实验性源码预览。部分运行路径已有技术验证，风格效果、真人修改后的完整作品链和具体编辑器兼容仍在推进。仓库写明已知问题、接入方式和来源条件，欢迎从一个有边界的小任务开始试用。

## 一句话介绍

让剪辑 Agent 不仅知道怎么改，也能说明改了哪里、依据是什么、结果是否真正进入作品。
