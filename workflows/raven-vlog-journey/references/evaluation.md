# W08 效果与执行验收

原子：用解码样本核对显式增益、首尾淡变、中段保持、声道/采样率、源缺音频尾部拒绝；无音轨不得合成现场声。混音完成后再检查声音，而非只看独立音频文件。

内容：给未看方案的观众能解释的作品承诺。人物线应能看懂人在做什么和变化；地方线应区分实际视角与虚构路线；活动线应有准备/参与/关键片段/真实结束或明确缺失。未经证实的陌生人关系、日期、因果或成功结果为内容失败。

制作过程另查[局部过程协议](partial-process.md)：开始是否已有成形对象，源内是否已有剪辑，是否把相似物件或重复动作当作同一次过程，结尾究竟是实际完成还是记录中止。对“完整教学”“尝试后纠正”的承诺逐项回源，不能用文件标题或区间覆盖测试背书。源片音轨未分类前不能称同期操作声。

多人活动按[参与与组间边界](participation-and-groups.md)检查用户指定人物是否实际保留、动作是否截断、不同组是否被拼成同一过程。漏声明窗口、错源绑定和截断区间可由映射负例验证；人物身份、日期冲突、跨组时序及镜头含义仍需内容复核。比较两版时标明是否使用同一素材池。

对照：同素材至少比较有实质不同的组织机制，例如空间认识与感官细节。保留事实一致，记录具体改了哪些镜头、声音和揭示顺序。两个长度或颜色预设不能充当两种独立风格。没有适配素材的风格只列已设计。

视听：按原始速度完整看最终文件，检查选段切点、动作残缺、音画接点、连续环境声、突然增益、对白可懂和字幕/人物/地标/HUD遮挡。抽帧、曲线、技术解码均不能代替完整视听。可以如实标一项未验收，不能让它自动升级其他项。

状态：设计卡→真实候选→实际视听→声明范围内验证。独立效果与Query评测另记。保持同一作品人工修改、源媒体和历史，宿主导入编辑再导出须在具体目标软件验收。
