# 案例解剖、速查复习与章节回看

## 先确定学习任务，再压缩

案例解剖让观众解释选择为何改变、结果提供了什么证据、哪些条件不能照搬。保留问题、关键选择、原因、结果检查和限制；不把最终成功倒推为当时唯一正确选择。若输入只有演讲录像，交付只能证明讲者展示了什么，不能宣称已复现其程序或实验。

速查复习面向已学过的人，保留概念触发、关键关系和易错边界；可省略已声明为先修的展开解释，但为忘记前提的人保留回看入口。请求压缩到某时长仍无法容纳必要条件时，先说明取舍，不把反例或限定移到观众无法发现的位置以假装完整。学习页中的解释可以补充编辑者的判断，不能冒充原声、已证事实或原讲义原文。

| 决策 | 案例解剖 | 速查复习 |
|---|---|---|
| 内容选择 | 展开情境、选择、反馈和机制 | 保留提示、关键关系、条件及检查项 |
| 例子与推导 | 保留支撑理解的过程 | 可省略已学步骤，声明先修并链接详解 |
| 答案提示 | 先提出解释问题，再回到证据 | 先尝试回忆，再展开提示；不自动判掌握 |
| 效果证据 | 观众能解释机制与迁移边界 | 已有基础的观众能正确回忆并定位 |

## 当前作品与时间映射

从修订后的当前作品派生，保留源身份、已有可读性修复和父子谱系。裁切投影等派生素材使用其本地时间；保留派生素材到原片的映射，不能把原片秒数直接用于输出跳转。

删除一个场景时检查依附该场景的图层、字幕、备注和知识单元。保留图层但前部缩短时，重算 clip-relative offset 和当前备注中的输出位置。课程中一张关键图表也可能跨段，不能仅靠锚点仍存在就认为覆盖正确。

`evidence-plan-compile` 中 prerequisite 表示必须先完整出现，context 表示必须保留、可在后解释。把需要保护的限定显式连接到主张；编译器不发现未声明的缺漏。每次文档变化均重新编译，用新报告的章节起止时间。实测输出页或字幕的跳转时间，不只比较 JSON。

## 可选学习页生成器

[build_learning_page.py](../scripts/build_learning_page.py) 接收显式学习提示和已编译章节，生成本地 HTML 与 `.bindings.json`。不选择内容、不批改答案、不写作品；没有学习页需求时不调用。

调用：`python3 workflows/raven-course-meeting/scripts/build_learning_page.py --spec /absolute/spec.json --output /absolute/new-page.html`（库根目录）。已有输出直接拒绝，使用新文件名保留历史。

输入 `schema: learning-page/1`；顶层字段为 title、summary、audience、prerequisites、limits、attributions 和 editions。所有文字由复杂层明确编写。

- attributions：`[{label, url, note}]`，URL 为 HTTP(S)。使用视频、讲义和代码的来源分别标注。
- editions 每项：id（小写字母起始，后续可数字/短横线）、label、purpose、selection_note、store（绝对 SQLite 路径）、version、document、video、render_receipt、evidence_map、exercises。四种文件引用均为 `{path, sha256}`。
- exercises 每项：chapter_id、prompt、hint；可选 revisit 为 `{edition_id, chapter_id}`，链接同页另一版的章节。chapter_id 必须来自所引用的证据报告，不接受手填跳转秒数。

生成器只读核对当前 SQLite 版本及文档、报告文档哈希、work-render 回执所绑定的版本和视频；拒绝旧版本、错配映射、错配视频和未知章节。按钮定位后暂停，用户决定是否播放。页面不持续连接数据库，作品后来变化需重新生成，不能把旧 HTML 称为实时编辑器。

通过 HTTP 打开后检查章节、跨版回看、提示展开、窄屏布局与真实 seek 结果。浏览器交互成功不证明学习者理解；提示答案也不是独立测试金标。HTML 可在来源目录的相对结构下使用，不能单独搬走后宣称媒体齐备。

## COSCUP 中文案例得到的边界

公开讲义可帮助识别 Wikidata/OSM、村里名称与数值，但与演讲原声不是同一证据。名称查询只有一个结果仍是推定对应；35000 多次描述请求数量，不是实测耗时；“一次查询”只覆盖特定检索步骤，不能抹去结果检查和预处理。复习版因此保留字段检查及结尾边界，省去策略展开和代码例子，并链接回案例版。

该案例使用已剪投影裁切和有署名的历史代码摘录，不是现场软件重演或恢复原投影片。初版第一处切点末尾出现即将被省略的下一页转场，后续在同作中缩短 3 帧并重新编译章节。ASR 句尾与新切点不相交仅支持模型时间观察，不认证剪辑听感。真实素材与当前报告见 `evals/runs/coscup-learning-01/result-current.json`（库根目录）。
