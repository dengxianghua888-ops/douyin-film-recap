# W06 效果验收

每次记录素材/作品/风格/运行时哈希、评审方法和观看范围。结构和技术测试、真实内容、完整视听、教学复现、原生编辑器分别给状态。

1. **内容回源：**逐项对照保留观点及其最强条件/反例；说话人、数字、责任与期限可定位，字幕不增强原话确定性。任何虚构决定、错误归属、删除关键否定均不通过。
2. **教学完整：**依据目标受众，能解释结论或跟做关键任务；公式、步骤、结果真实可见。未做实际跟做不能声明教学有效。
3. **声音与画面：**完整播放听检，不只看抽帧；检查残句、抢话、音量、字幕可读性、板书遮挡、章节跳转和同期关系。测量时间一致不证明口型正确。
4. **风格对照：**同素材不同机制的保留/删除/重排/声画差异列明；观众能区分用途，且没有因风格丢失必要信息。审阅者不足时不冒充独立盲评。
5. **修改与恢复：**已有作品局部删改，相关章节重新计算；冻结轨道和人工修改保留，恢复产生新版本，旧回执不绑定新文件。
6. **独立 Query：**课程/会议与访谈/软件教程、只写纪要/成片、参数操作/内容判断的边界分别测量；开发 Query 不作为覆盖正确率。
