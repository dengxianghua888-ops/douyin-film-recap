# 真实生成任务与恢复

本页是运行 Agent 选择并调用外部生成工具时的风险与结果回接参考，不是 W14 Skill 要求安装本库生成账本或某一模型。Skill 消费 Agent 回交的实际候选身份、来源、状态和媒体结果，并负责内容评审与作品局部采纳。

执行前确认工具可调用、账号能力、实际模型schema、输入资产可访问与费用边界。不要读取／回显密钥；凭证由环境或宿主管理。批准与需求沿用会话，不继承来源Skill的逐镜重复审批。

运行 Agent 沿原工具或已有任务记录保存可核的请求指纹、provider/model、输入身份、参数、提交时间、任务／interaction ID、状态、费用（未知则unknown）和输出身份，不要求本库generation-task字段或另建账本。能读取字节时记录输入／下载hash；只有稳定资产ID时绑定项目／修订并标明字节hash未知。保存原响应；需要下载而下载失败时只重取同一输出，不能重生成。传输超时可能已受理，保留UNKNOWN_SUBMISSION并先按请求ID或服务任务查证；没有查证能力就保留不确定并暂停该次提交，继续其他已授权工作。取消请求送达不等于任务已停止或费用为零，未确认终态前不据此重提；身份不足以安全查询或采用时只阻塞相应步骤，不伪造缺失字段。

状态至少区分prepared、submitted/running、unknown、completed-with-output、completed-empty、failed、downloaded、accepted/rejected。accepted是复杂层实际评审，不是服务返回success。成功无输出不凭空归因为地域限制，保留服务原错误并核对官方条件。随机生成不承诺同请求同字节，幂等键应约束提交而非假定模型确定性。

保存原始候选和每次修改；预算耗尽／服务不通只阻断相关分支。相同失败重复出现时根据证据换锚点、改规格或换经授权且可用的路径；不机械重试到收费次数耗尽。已有合格候选可评审剪辑；尚无候选且当前 Agent 有实际能力、授权与预算时生成候选并评审；能力不可用或生成后仍无合格候选时，只交实际完成的图文、脚本/分镜和可执行规格。不因本库本地适配器缺失断言其他工具不可用，也不虚构 job_id。
