# 执行路径与作品状态

以下本地路径是本库可选实现。运行 Agent 可用实际编辑工具执行等价操作，并按[能力交接合同](../../../contracts/capability-handoff.md)回接作品、版本和输出；生成服务不由本 Skill 选定。

本地路径：源文字／图片版本→声画表→真实TTS（若需）→按真实声音时长决定整数帧→明确静图运镜→作品init或read→scope候选→commit→work-render→检查。源图来自视频抽帧时保存原视频和抽帧回执；静图运镜不继承原摄像机运动或现场声音。

静图原子输出无音轨。复杂层决定无声、旁白、原声摘录或音乐，并用已有音频原子明确摆放；声音来自别的时间或位置时不得冒充同期。TTS声音质量未听检就不能称自然或符合人物。字幕按可靠时间或明确显示窗口组织；显示分箱不冒充逐词对齐。

候选路径：已有合格素材先核来源、授权、版本和镜头规格；缺素材且需要新生成时，运行 Agent 核当前能力并负责实际模型调用→取得候选。两种来源都回交实际任务/资产身份→探测及完整评审→采用→作品局部提交。不要求本库提供生成适配器；没有实际候选时保留该阶段缺项。模型输出帧率/颜色/音频常与请求不同，先探测后决定明确规范化。生成缺口与编辑器缺口分别记录；普通MP4不能充当原生可编辑工程。

保留每段与beat／原文的映射及可核实的来源身份；能读取字节时记录hash，只有编辑器稳定资产 ID 时标明字节哈希未知。局部替换只失效有关生成／渲染／QC；冻结原旁白时不能为新画面任意改文。当前本地work document可继续修改，不代表ChatCut/剪映/Resolve已接通。
