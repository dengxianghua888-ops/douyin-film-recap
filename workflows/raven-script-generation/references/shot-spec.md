# 镜头规格

每镜包含shot_id、beat_id、用途、来源身份、媒介（实拍／静图运镜／模型视频／图形／数字人）、预计及实际时长、画幅、主体／动作／场景／机位、声音要求、锚点引用与版本、固定项／可变项、相邻镜头连续性、正负检查项、选择原因。

生成调用由运行 Agent 按现有授权选择实际工具／模型，记录可核的provider/model及当前能力、原文prompt、参考图像／视频／音频的角色、首尾帧／编辑目标、参数和任务／输出身份。来源能读字节时记录hash；仅有编辑器稳定资产ID时绑定项目／修订并明确字节hash未知，不能为凑字段伪造哈希或强制本库账本。提示词与镜头规格由复杂层负责；执行工具按已定规格操作，不擅自换模型或把“更高级”当明确参数。模型能力、价格、地域等由Agent按实际服务核对，不把归档上限当当前保证。

静图请求必须给定逐帧关键点与源像素裁切框。frames−1是末帧，不把总帧数当合法末索引；多段hold可通过相同矩形关键帧实现。画面文字需要稳定阅读窗口；不裁掉署名、尺度参照或事实限定。显式放大也要评估源分辨率和文字清晰度。
