# 候选选择与补足取舍

先按镜头用途评价：直接说明要准确可读，气氛镜头要与段落作用一致，连续动作要有完整起止。逐镜记录接受／调整／弃用、原因、证据区间、未查范围。技术完整性与审美偏好分开，不用一个总分掩盖人物错误或虚假事实。

看首中尾及动作／形变／字幕变化点，必要时全片逐段重看；首尾正常不能证明中段手脚／道具／文字无漂移。声音单独检查对白、音乐、同步与生成多余音效。品牌文字、图表数字和科学示意优先使用可控制的真实文字／图形图层，不让视频模型猜。

候选比较固定脚本、声音与目标，明确变化维度。取舍可以保留较朴素但内容正确的候选，但不能因易通过技术检查而把用户要求的动态叙事替换成静态片。无法实现的原目标继续登记，替代只作为明确局部交付。
