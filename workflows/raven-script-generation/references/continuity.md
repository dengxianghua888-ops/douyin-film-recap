# 连续性与视觉锚点

按需要建立人物外观／服装、物件形状／标记、地点地理、光向／天气、动作开始结束状态、银幕方向和声音位置。每个属性记录来自哪份真实资产或本作品的虚构设定；只有文本设定不能冒充视觉一致性证明。

已有锚点优先复用；独立人物用独立引用和身份，不把衣色／道具串到另一个人。相邻镜头检查动作接续和轴线，参考首尾帧不能保证中间动作正确。对话反打需检查视线、空间和说话归属；单张角色图没有证明身体背面与运动一致。

一致不等于静止：景别、构图、光照或时间可以按剧情改变，但变化需有依据。允许有意风格断裂或主观幻想并标明机制。局部修改复核整个生成片，而非只看修改区；真实用户冻结区域若无法保证，保留原镜头并给候选，不静默替换。
