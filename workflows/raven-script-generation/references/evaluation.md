# 验证与交付

技术：输入/锚点/脚本/服务规格/资产/作品/最终视频版本链、整数帧、声音完整、字幕覆盖、无越界运动、文件实际可读。服务产物须由实际工具访问并读回内容与必要媒体规格，绑定任务／来源／资产身份；可获取文件时保存下载和探测回执，只有编辑器稳定资产ID时记录项目／修订与字节hash未知，不强制本地下载或probe。仅输出URL或服务success不构成产物已核验；缺必要内容／规格读回，或明确要求字节冻结却无字节／可信摘要时，保留该项不可验证。静图运动的两端与关键点比对实际画面。

内容：原文意思与归属、生成／示意身份、镜头作用、角色与物件连续性、空间方向、动作正确性、语音与字幕。创作：画面组织、阅读时间、运动动机、声音分工、风格辨识与目标适配。完整看听和独立效果没有实施时保持未验证。

真实评测至少覆盖图文已有图片、纯脚本需要资产、已有作品局部补足、连续角色多镜、生成失败恢复。未接通服务时不能把本地静图案例外推到后四项。目标语言和宿主能力分别验收，计划／本地试验／原生交付不能混为一谈。

交付说明已采用和未采用候选、实际模型／本地工具、费用和未知项、时长/画幅、图片／生成来源、可编辑状态、当前输出和QC、具体阻塞。没有生成模型不算W14完整验证，但仍完成可独立执行的图文能力。
