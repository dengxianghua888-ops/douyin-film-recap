# 声画脚本与事实边界

每个beat记录目的、原文引用／文本版本、事实或虚构身份、旁白、画面承担作用、可用资产、必要生成与保护项。文稿可压缩时保留否定、限定、数字、人物归属与因果；纯排版不得擅自改写。图文成片可以完全无旁白，不能默认朗读所有屏幕文字。

双列声画表用于发现重复和缺画：声音补不可见关系，画面给具体动作／证据。科学机制示意和历史演绎要在观看当下可区分，不能只在报告角落解释。反复使用同一照片属于有意母题或缺素材，明确说明，不伪造新拍摄时刻。

时长用实际音频和阅读负担校正；中文、数字、专名、停顿与表演不套统一英文wpm。声轨超长时改脚本、镜头安排或明确延长，不能偷偷加速／截尾。镜头只给静图时承认其局限；任何移动都需有阅读或叙事作用。
