# 事实、体验与表达

针对实际要表达的句子或视觉暗示建表：主张ID、精确表述、所属型号/版本、来源文件与SHA、证据区间/页段、适用条件、来源类型、采用/限定/舍弃、出现位置。无必要的表不强制填写。

| 类型 | 可支持的范围 | 常见错误 |
|---|---|---|
| 当前实拍演示 | 这次、这台、画面可见动作与结果 | 一次演示推成普遍耐久、速度、安全保证 |
| 本人真实体验 | 该说话者在所述条件的感受 | 拼接原话删掉“不适合我”，替别人写第一人称 |
| 官方规格或说明 | 对应版本声明，注明来源与条件 | 把品牌说法当独立实测，跨型号配画面 |
| 报价、促销、库存 | 特定渠道/时间/规格、可核对凭据 | 虚构最低价、倒计时、售罄、销量和评价 |
| 品牌自述 | 品牌表达的理念、经历或目标 | 宣言当已达成环保/公益/效果事实 |
| 演绎/生成画面 | 经明确表达的情境、示意或创意 | 把生成水滴当防水测试，演员当真实购买者 |

证据引用能证明“来自哪里”，不自动证明“该结论正确”。参考片、竞品页面、外观相似产品不能转移效果、声誉或商标背书。产品一致性须核对款式、结构、颜色、配件和使用阶段；型号未知时保留未知，用画面范围内的表述。

对比要说明同条件程度：同源前后或不同人/日期/机位，是否调色、调速、裁切、替换音频；不可通过改变亮度、音乐、速度制造产品优劣。无法公平比较时改成两次观察，或不保留比较结论。

限定条件需与主张一起被理解，不能只藏在片尾。复杂层确定精确文字和窗口，再让caption-coverage-check验证覆盖。连续显示也不等于易读；最终检查文字大小、阅读量和产品遮挡。没有主张时不强加与内容无关的免责声明。

真实购买体验需该人实际说过或用户提供可信经历；授权演绎可表达角色台词，但不能伪造真实消费者见证。授权素材许可并不等于品牌代言授权。本库的公共许可评测素材仅作剪辑研究，说明出处与无背书，不投放为商品广告。

源人物说的话、旁白、字幕分别核验。字幕正确不能掩盖声音说错；ASR只提供观察，品牌词、否定词、数字和条件需回听。未知就不扩大声明。
