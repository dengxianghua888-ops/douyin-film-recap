# 译配与同步

先明确新选合成音色、录制配音还是经授权的原音色保留；记录角色与声音映射，不能因同一speaker_id就认证身份保真。TTS请求保留精确文本、voice／provider、参数和真实输出。普通TTS不产生可信逐词对齐；字幕可用句级窗口并标明，不能伪造词时间。

实际音频长于窗口时，复杂层可重写不损义表达、重录、调整允许的停顿或画面；若必须严格等长且保护内容无法容纳，报告冲突。原子不截尾、不盲目加速。音节、字数和wpm只能估预算；短稿不能为了填满时间硬添内容。

替换对白需要M&E或可验分离；压低混合原声会同时压低环境、音乐与效果，不声称只去人声。Noiz的按SRT静音方法只保留窗口外声音，重叠窗口还可能错误恢复音量，因此不直接继承。覆盖式译述要明确原声可辨窗口和译声起止，声音冲突必须听检。

同步分实际时长适配、短语起止、音素／口型、人脸自然度；前一层通过不推出后一层。近景、侧脸、遮挡和多说话人分别检查。本库可选本地 runtime 未提供原声克隆／口型适配器；运行 Agent 如有真实服务须先核授权、能力与结果读回，否则只保留规格与未验证状态。真实服务任务沿用已授权范围和费用边界，记录原任务而不超时重提。
