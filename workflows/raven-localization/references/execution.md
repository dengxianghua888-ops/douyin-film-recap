# 执行、版本与局部修订

先按本次模式读取源视频、已有稿/SRT及当前作品（如有），由当前 Agent 用获授权工具生成译文候选（或接入已有可核来源译文）与源单元映射，复杂层逐条复核字面义、数字、否定、专名与语气。ANALYZE/PLAN止于所求分析/方案；纯SRT止于已核文本、时间标记和文件读回，不强制建视频作品、配音或渲染，也不认证未查的源声/画面时序。EDITABLE交可继续修改且绑定当前来源/修订的字幕、声画计划或工程，按用户范围止于候选，不自动采用/渲染。明确PRODUCE或已授权REVISION才继续实际所需的字幕窗口、可选真实配音、受限采用、导出与相应看听。

按[通用能力交接](../../../contracts/capability-handoff.md)使用当前 Agent 的实际编辑与读回工具；localization-plan-compile→scope candidate→commit→render是选择本库本地Work后的可选执行路径，不是所有请求的固定前置。已有可靠逐词稿可跳过ASR；仅字幕不触发TTS；无字幕交付不触发烧录。编译只消费已评审的文本与窗口，输出不自动覆盖作品；title、正文字幕、音轨、notes逐项声明范围，主风格不变。

来源工作文档变化会使旧source_script和translation绑定失效。局部改一句时读最新版本，保留已校对邻句、声音、切点与用户文字，只重建该句及受影响的时长／音频／字幕。只改字幕文案不得顺手重合成全部声音；只改一个专名时核查它实际出现的所有必要上下文，避免全局替换误伤同形词。仅恢复某句译文时，从历史取授权字段合入最新作品，保留后来字幕、音量、画面与兄弟语言的手改；不以整版回退代替局部恢复。外部写入超时/取消/部分结果按通用能力交接先核原操作终态与同作字段读回，未知状态不盲重放；缺安全读回仅阻塞该写入。

多语言版本从明确父版本派生，保留每语种当前状态与对照，不让后做语言覆盖先做语言的人工修订。W15验证单语言与同作修改，W16负责队列、批量导出与失败恢复。服务已提交而未知时先查询同一任务，下载失败只重取；没有服务就不虚构费用或job ID。
