# 参考适配验收

技术：参考/目标/来源/LUT/字体/计划/当前版本/实际视频hash绑定，指定操作有效，帧钟和音轨保留符合合同。颜色看代表肤色/高光/暗部/品牌色；构图看关键动作与读字；字幕看完整画面而非单独样式卡。技术检查不会判断像不像。

机制：逐条指出参考证据和目标中的对应作用；解释有意不同的地方及素材不支持项。目标单独观看时必须成立，不依赖用户记住参考才读懂。对照变更以同素材控制，区分喜欢音乐、画面漂亮与真正迁移了组织方法。

完整看听参考和最终片；抽帧只支撑对应画面范围，不能认证声音、动作和情绪弧线。若暂不可看听，明确DEGRADED并保留样片，不能把小样片数量算已验证风格数。

负例：旧参考hash、被替换的LUT、未经授权的字幕更改、跨色彩空间误用、缩短导致动作证据截断。独立路由/独立风格辨识另行评测；来源自有对照只验证方法实施，不代表外部参考泛化。

状态排序负例：前后片段都已有成形对象，却仅因时间靠后命名为“更完整”；参考仅从展示转为手触就解释为成品回溯；只有相反排序和帧匹配却登记迁移有效。以上不得通过机制验收。静音控制实验只验证声明的视觉范围，无音轨不能登记完整声画验收。真实拒绝案例见[W13 恢复报告](../../../docs/evidence-scope.md)。

2026-09-23另完成[动作→后续反应的视觉对照](../../../docs/evidence-scope.md)：跳高为外部参考，足球扑点为目标，Gigaset为排除候选；19源帧与12输出锚帧记录了具体动作和反应差别。两条8.5秒/255帧静音视频使用同一组目标帧，只改变A/B顺序，完整解码及缩略帧置换检查通过。目标此前用于W07且原本已有动作→反应顺序，因此只证明在兼容素材上的选段保持与显式排序，不证明创造新结构或独立跨素材泛化。

该试验绕过共享runtime制作，不能登记为原子合同或同作采纳成功；完整观看、声音、独立理解/审美、真实手改/恢复和宿主均未验。参考的落垫、目标人物反应不代替正式成绩判断，实验倒序也不是倒叙天然错误的证据。旧陶艺候选维持拒绝；`long-take-attention`、`ending-weight`及W13整体验收不升级，具体状态见[终态结果](../../../docs/evidence-scope.md)。
