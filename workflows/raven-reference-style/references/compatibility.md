# 兼容性与冲突

参考中的广告承诺不能迁移到没有证据的商品，影视悬疑不可把新闻事实伪装成未知，旅行路线不能由相似风景拼成。完整动作/原话/必要前提先于参考的固定秒数；目标受众阅读速度先于字幕闪动节奏。

长短不同不按比例缩每个镜头：先找承担相同作用的单元，再分配时长。镜头内运动少的素材可能无法承担参考的长持；给出可见变化、换机制或说明不足，不冻结/重复填充。

多参考按维度分工：叙事A、声画B、文字C可以兼容，但三者争同一注意力时需删减。以用户指定优先级为准，未指定时服务目标内容；不能以折中平均得到全都不像的混合。可反向参照：保留声音连续却让画面更疏，需明确这是有意区别。

颜色先查解释链：未知SDR色彩空间明确假设；HDR/Log需要实际变换能力与验证，本库当前LUT原子不支持。不能对所有镜头同套造成肤色/产品色/图表编码失真。颜色改变不可暗示历史年代、病态肤色或产品真实属性。

画幅改变先确认信息边界，不能裁掉手、结果、字幕或关键关系。参考字体不可用时选有来源的可用替代并说明形态差异；动效不支持则明确未实施，不以静态标题冒充动态同款。
