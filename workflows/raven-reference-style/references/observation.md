# 参考观察与证据

记录参考文件hash/字节数、出处和使用范围、源帧率、音画版本、时码基准。完整看听状态分开记；无音频访问或只看接触表时不能断言音乐、台词语气和连续动作。用户只提供截图时可以做画面观察，节奏与声音未知。

观察维度：叙事的提问/预期/信息揭示/回收；剪切的长短变化与画内运动；画面的景别、主体位置、方向、负空间、色彩关系；声音的原话/旁白/音乐/环境角色；文字的层级、阅读时间、位置与运动。每项附具体时间区间/帧证据和反例，不用导演名字替代分析。

低成本抽样用于定位候选，转折、动作完成、字幕变化需要密集回看。镜头边界检测只是候选；闪光/相机移动可能误报，叠化/匹配剪辑可能漏报。接触表标签不能当源帧的精确PTS，关键点用明确帧或可靠时间映射复查。

统计镜长、密度、归一化切点、段落占比可帮助比较；少量样本不推整个创作者习惯，更不推留存率或受众效果。人声停顿、表演细节与情感意义不由统计自动生成。

涉及“结果先行”“状态递进”“过程回溯”时，逐个记录同一对象的可见状态特征、对应动作窗口及身份连续性证据。较晚出现不等于更完整，手接触不等于正在从原料成形；展示与操作都可能围绕同一已成形对象。状态差异或先后因果不明确时保留未知，不用片段名称或排列顺序补齐前提。
