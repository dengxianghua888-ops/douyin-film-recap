# 节奏重构验收

同素材同主风格比较，记录变化变量及目标，不把更短默认判胜。技术核对实际帧数、帧率、声画长度、来源/卡/工程/导出hash、保护范围和历史；内容回源核对否定/限定、论证链、说话人、动作及信息归属；观看原速完整成片，听每个接点及音乐结尾，读字幕。截图、音频相关性或样本峰值均不替代完整视听。

对照问题：删去后是否仍能正确复述观点与前提？舒展后新增时间在看什么？原声是否自然？原风格和人工修改是否保留？硬时长是否满足，软目标偏差是否有解释？快慢变化是否与内容变化对应？

每个节奏版本先声明本版回答的问题，再列内容单元差异：保留、移除、恢复及其前提依赖。对原话/会议素材，至少绑定说话者、来源区间、否定与条件词，以及该句是事实、估计、提议、异议还是回应。压缩版可以明确收窄问题并删除完整旁支，但不能删掉当前保留主张的成立条件；舒展版声称恢复争论时必须同时恢复被回应的主张、异议和回应。时长、固定字幕间隔、解码通过或evidence-map覆盖均不能替代这项语义回读。

人工修改保护须记录可审计的真实事件来源，例如用户提供的当前作品、目标宿主内观察到的修改，或明确的用户操作回执。`author: human`只是调用方声明；Agent创建的标题、备注、冻结区或测试注入只能验证范围/冲突机制，不能称真实用户手改已保留。没有真实事件证据时单列`EVIDENCE_GAP_RETAINED`，继续验证可独立成立的内容保护项。

负例应尝试切掉指定证据的一部分、缩短却锁后段位置、未经范围许可改标题、旧版本提交或把新输出套旧QC，确认拒绝及当前作品未变。不通过不能通过重新生成hash或删掉失败样例洗白。

每卡状态：authored-unvalidated → 产生真实候选 → 完整看听 → 声明素材范围内效果验证。前后作品、证据和评审范围独立绑定。真实英文情景会议不认证中文口播，自然风景不认证表演，结构合格不认证独立路由。

本包逐帧修复后的六份导出必须重新抽帧，旧图片仅保留历史。基于源原话区间的保护不等于所有发言已听清，固定四秒字幕分箱不证明阅读速度或逐词同步合格。公开评审前需补这两项。


## 中文硬时长冲突的有界开发案例

AISHELL-4 M_R003S01C01中文录音补充一例15秒硬上限冲突：开发请求要求保留中途安排及工作量、数量和未满原因，复杂层据发布标注允许删议题引入单元12，但保留完整单元14/16。原速连续跨度16.95175秒；即使移除约4.94ms间隔，完整必要单元并集仍16.9468125秒。故原15秒请求明确拒绝，未将限定或否定删去，也未以变速/伪词界通过。

单列18秒替代预算后，实际audio-extract输出16.95175秒/271228样本，与源channel0对应PCM逐字节一致；原15秒仍未满足。见[开发结果](../../../docs/evidence-scope.md)与[来源及改动](../../../docs/evidence-scope.md)。请求、内容判断与参数在执行前冻结；该判断为Agent依据发布文本作出，不是runtime语义拒绝或独立真人请求。无内部词剪/变速，无伪造人类修改；自然边界、完整听检、独立节奏效果和宿主仍未验收。此处新增中文冲突/替代证据，不升级旧英文AMI案例或风格等级。
