# 压缩：先减任务负担，再修切点

首先明确片子此刻承诺回答什么。按内容职责审查重复解释、旁支议题、过程冗余、镜头尾部等待；删减依据是当前目标，不是字数、静音阈值或镜头长度。把“有点、可能、只有在、不”删除可能改变主张，应回源对照。

可用顺序：收窄已授权主题 → 合并重复信息但保留条件变化 → 移除不承担因果的旁支 → 压缩已完成动作之间的等待 → 在自然边界修切点。不要对所有题材机械按此顺序；用户要求原话全文时前面几步均不能擅用。

论证保护：观点的前提/证据/例外/反方/回应；对话保护：问题对象/回答条件/实际发言人；动作保护：起势/接触/结果及空间连续；教程保护：前置状态/操作/反馈/可复现性。离开这些单元的片段可以在别的版本保留，当前片子不谎称覆盖了被移除的话题。

字幕展示分箱不是可靠逐词切点。独立音频按各段明确同步映射，保持声画来源。真正听检前只称转写支持的候选，不称无残音。语音变速需要用户约束、真实处理能力和复核，不靠修改时间戳实现。
