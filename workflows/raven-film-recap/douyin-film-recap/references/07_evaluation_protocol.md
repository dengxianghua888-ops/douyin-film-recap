# 评测协议

## 1. 评测目标

评测必须区分：

- 流程有没有跑通
- 内容有没有讲对
- 高光有没有找准
- 成片是否值得发布
- 人工需要改多少

## 2. 测试集

至少覆盖：

| Case | 重点 |
|---|---|
| 多角色群像 | 身份、关系、说话人 |
| 悬疑反转 | 揭示顺序、剧透 |
| 动作片 | 动作完整、空间、声音 |
| 家庭爽剧 | 羞辱、反击、站队 |
| 爱情文艺 | 表演、反应、留白 |
| 喜剧 | 包袱、反应、节奏 |
| 低对白影片 | 视觉理解 |
| 多集连续剧 | 跨集人物、因果、记忆 |

再加入：

- 无字幕
- ASR 噪声
- 中英混说
- 相似角色
- 闪回
- 梦境
- 横竖屏混合
- 长片
- 多源文件

## 3. 高光金标

每个 Case 由至少两名评审标记：

- Must Keep
- Good Optional
- Reject

记录：

- 类型
- 时间
- 最小完整边界
- 必须原声 / 可 VO
- 故事作用
- 人物
- 评分分歧

指标：

- Top-10 Must Recall
- Top-30 Recall
- Precision@10
- 类型覆盖
- 边界完整率
- 原声必要性准确率

## 4. 故事准确

- 人物错误数
- 关系错误数
- 事实错误数
- 因果错误数
- 提前剧透数
- 角色知识混淆数
- 不受证据支持的动机推断数

关键事实错误应按严重度加权。

## 5. 成片质量

### 结构

- 开头承诺
- 主线
- Beat 变化
- 中段重启
- 高潮
- 结尾兑现

### 视听

- 原声完整
- VO 不重复
- 动作完整
- 表演保留
- 字幕可读
- 画幅安全
- 音频舒适

### 风格

- 是否机械模板化
- 是否存在同质 VO
- 是否只有大声与动作
- 是否有题材适配

## 6. 端到端指标

- 任务完成率
- 首轮可发布率
- DEGRADED 率
- BLOCKED 准确率
- 平均返工轮数
- 断点恢复成功率
- 每分钟源素材成本
- 首次预览等待时间
- 总耗时

## 7. 北极星指标

```text
每 1 分钟可发布成片所需的人工修正分钟数
```

配套：

- 人工替换镜头比例
- 人工改写 VO 比例
- 人工调整切点比例
- 人工修正事实数
- 人工恢复原声数

## 8. 人评 Rubric

1–5 分：

- 剧情准确
- 人物准确
- 高光命中
- 原声价值
- VO 可听性
- 节奏
- 情绪 / 爽感 / 悬念
- 画面与声音匹配
- 字幕与画幅
- 可发布意愿

3 分定义为“基本可看，但仍需明显人工修改”。  
4 分定义为“少量修改即可发布”。  
5 分定义为“直接发布也不显得粗糙”。

## 9. 回归

任何模型、Prompt、召回、TTS、时间线或渲染变化，都应跑固定回归集。

不能只看平均分。必须检查：

- 最坏 Case
- 人物混淆
- 剧透
- 残句
- 无台词高光漏召回
- 版本回退
