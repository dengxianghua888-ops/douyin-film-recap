## 发布长文案

我开源了 **Douyin Film Recap**，一套面向 Agent 的中文影视解说 Skill 与本地制作流水线。

很多自动解说工具解决的是“把文案配上画面”，但影视解说真正难的地方在更前面：谁是谁、因果怎么成立、观众此刻知道什么、哪一秒是表演而不是空镜、哪句台词必须完整留下，以及开头够不够抓人又会不会提前泄底。

Douyin Film Recap 从字幕、镜头和原片证据开始，重建人物、事件、因果与揭示顺序；再召回冲突、动作、台词、表演、情绪、反转、喜剧和关系变化等高光，规划主线与 Beat，编译成可修改的 Storyboard，最后完成分段配音、原声保留、中文字幕、竖屏渲染和质量检查。

它有几个我很在意的设计：

- **先理解，再剪辑。** 关键判断能回到素材时间，不让旁白凭空补动机。
- **原片负责出刀，旁白负责连接。** 强台词、动作、反应、停顿和表演尽量留给原片。
- **高光不只看音量。** 一个眼神、一次关系变化、一个喜剧停顿，都可能比争吵更重要。
- **人可以随时接手。** 高光、方案和分镜都是结构化中间产物，修改一段不必推倒重来。
- **不把导出成功当作品成功。** 文件、内容、最终画面和实际声音分开验收；缺少证据时明确降级。

v0.2.0 已有 80 项自动测试，并用真实 FFmpeg 验证合成素材的竖屏渲染、混音、中文字幕和 EDL。它仍是一个需要真实素材、模型配置和人工复核的 MVP，不承诺爆款，也不会把合成回归包装成生产级内容质量。

如果你在做影视内容、Agent 视频工作流、自动剪辑或长视频理解，欢迎试用、提 Issue、补 Provider，或者带着合法素材一起建设真实评测集。

项目地址：https://github.com/dengxianghua888-ops/douyin-film-recap

## 社交平台短文案

开源了一个我一直想要的影视解说 Agent：**Douyin Film Recap**。

它不只是“写文案 + 随机配画”，而是先理解人物、事件、因果和揭示顺序，再找动作、台词、表演、反应、喜剧和关系变化中的真正高光。之后把主线、Beat、旁白、原声和镜头编译成可修改的 Storyboard，最终输出 MP4、SRT、EDL 和质量报告。

我最看重三件事：原片负责出刀，旁白负责连接；每个关键决定能回到素材证据；没有真的看过、听过，就不把成片标成通过。

支持 Codex / Claude Code / Cursor，本地 Python + FFmpeg 运行，MIT 开源。

https://github.com/dengxianghua888-ops/douyin-film-recap
