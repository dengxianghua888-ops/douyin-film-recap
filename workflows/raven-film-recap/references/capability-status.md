# 当前可执行范围

状态：本库本地执行器的历史可执行范围快照（于 runtime0.13.0 后复核）；不描述当前 Agent 的全部编辑/模型工具，也不授予整个 W01 作品或风格效果通过。现行通用交接见[能力交接合同](../../../contracts/capability-handoff.md)，实时能力按当前工具核验。

| 环节 | 当前状态 |
|---|---|
| 意图、故事、风格与声画规划 | Agent 读取证据后执行；有方法与风格卡，真实质量尚待评测 |
| 本地源身份、媒体规格、抽帧、音频提取 | 已实现原子脚本；有合成媒体真实 FFmpeg 集成测试 |
| 明确源区间的原声拼接、画幅、固定增益 | 已实现本地渲染；支持执行计划 JSON |
| 原文字幕映射、SRT、单层字幕烧录 | 已实现明确输入的映射与渲染；不是自动转写、语义校正或重叠多字幕轨 |
| 同一作品、增删/重排、冻结位置及局部恢复 | 已实现SQLite WorkDocument、scope差异、比较提交和历史恢复；真实编辑器选区/播放头未接入 |
| 父子风格版本与本地批量导出 | 已实现明确派生、哈希复用和失败恢复；无自动合并父版修改、云任务或发布 |
| 真实云 ASR/VLM/TTS | 未接入库合同，未完成真实调用验收 |
| 本地 macOS TTS | 已实现显式音色/速度/文稿合成与真实时长探测；听感/情绪质量未验收，不替代指定云提供方 |
| 已有旁白/音乐的多轨混音、字幕烧录 | 已实现明确参数的本地操作；不含生成/自动对白避让/响度处理，实际视听效果未验收 |
| 最终画面/听感/叙事验收 | 需要真实素材和实际复核，不以自动结构通过代替 |
| ChatCut/剪映/Resolve 可编辑工程 | 未接入；不得将本地 JSON 宣称为对应原生工程 |

按全链路目标持续补齐；本表不是降低目标，也不是把未实现功能永久排除。
