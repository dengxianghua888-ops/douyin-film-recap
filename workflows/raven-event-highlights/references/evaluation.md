# W07 验收与失败归因

技术测试关注源哈希、真实PTS、短事件测量、音频末窗、无音轨、完整阶段、明确open、回放标识和版本失效。合成单帧闪光可以证明没有被固定抽帧跳过，但不是实际球体/精彩事件召回。

真实评测按直播、游戏、体育分别建立素材集和事件标注，记录标注来源及复核方式。漏检以完整源片审阅得到的事件清单为分母；仅核对系统找到的候选不能计算召回率。错误得分/胜负、裁掉结果、伪造反应和重复计事件是严重失败。

风格对照：同素材相同事实，检查铺垫/动作/结果、选择顺序、声画分工差异和观看理解。纯动作、战术解释、人物反应、幽默回调、比赛回顾应有不同的信息组织；只换音乐不计新风格效果。

全部最终样片需连续观看与听检；样帧只证明其局部画面。无声源应明确无声，不能用静音音轨通过audio_required后声称现场音完好。字幕、比分和球/光标遮挡按实际输出检查；缩放后小球丢失属于内容失败。

真实编辑器导入、人工修改、再导出单独验收。独立Query评测与开发样例分开；不能以技术测试数量或卡片数量称覆盖大部分用户指令。每个风格保持证据状态，未做域内真实验证的卡继续authored-unvalidated。
# 已观察的真实边界

W07 本地候选曾把游戏署名放在底部，遮住开场物品栏；已在原作品内调整字幕位置。字幕安全区须检查当前素材的实际 HUD、比分、聊天与关键动作，不能跨场景沿用固定底部边距。具体失败帧与修订证据保留在 `evals/runs/highlight-style-trials-01`。

跳高试验 `evals/runs/high-jump-replay-01` 增加两段同赛事不同运动员/服装的真实素材。可见动作链与官方成绩分开记录，不依据文件序号建立比赛进程；仅是同一 moment-replay 机制的素材扩展。初版回放提前结束和字幕过小已修订；手机控制栏遮住标签的截图触发第二次同作位置修订。未见判定/未听原声不能随技术报告升级。具体处理见 [单次尝试与回放](attempt-replay.md)。

点球防守 `evals/runs/penalty-save-01` 对照保留准备等待的连续版和缩短准备/加入回放的防守版；两作是同素材机制对照，未通过独立风格评审。防守动作显式依赖后续结果：删结果实例、截掉结果媒体、回放标识过早结束分别拒绝。源说明与可见球路分别登记，不直接认证姓名、正式判罚或全场比分。具体见 [防守结果与保护](defensive-outcomes.md)。
