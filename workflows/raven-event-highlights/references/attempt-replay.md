# 单次尝试与回放

适用于跳高等“助跑/准备—动作—落地或停止”的单次尝试录像。先声明交付目标是可见动作记录、技术观察还是正式成绩回顾；原子编译器的 complete 只校验已声明阶段，不认证成绩。

## 动作与结果的两条证据

- 动作记录可以用助跑、腾空、落垫和起身作为可见阶段；记录开始前的准备依然未知，不能声称完整训练或整场比赛。
- 成绩回顾需要对应运动的规则与可归属的判定/结果。身体越过某个高度、横杆似乎没掉、显示牌数字都不能单独推出有效成绩；保留落地后的旗帜、判定和更正窗口。判定未建立时标未知，必要时将正式结果事件保持 open。
- 文件 01/02 是素材身份，不自动等于第一/第二次尝试、赛事时间顺序或同一运动员的进步。跨片比较须先核对人物、项目、条件和时间。
- 画面中实际看不清的横杆、接触点和技术角度保留不确定；不把姿态观察写成力量测量或专业诊断。

## 回放组织

先给当前可用的连续动作与后续，再重复同一事件。回放选区应留够起跳前的方向和落垫后的恢复/判定，不在腾空最高点或刚落垫时停止，以免暗示成功。用于细节观察时可缩短，但说明观察范围，不顶替已保留的主事件。

未设置 clip.speed 的回放只可称“源片 1×播放”；明确 0.5–2 倍恒速可走 timeline-render，标明回放速度并核实动作、字幕和原声时钟。普通帧采样不等于光流补帧；来源自身可能已加速或慢放，未核查拍摄/转码关系时不认证现场正常速度。回放原声也重复发生，标签须让观众知道它不代表第二次现场事件；不加借来的欢呼。

标签在实际交付尺寸和播放器状态检查。横屏缩进窄屏时，底部标签可能落入控制栏；针对素材找能保持人物、器材和判定信号可见的位置，不能固定所有视频都放顶部。字幕位置修订沿用原作品，保护片段、增益、文案和时间，更新事件与渲染绑定。

## 本地实证与限制

`evals/runs/high-jump-replay-01/result-current.json` 指向两段 2019 Montevideo 跳高录像的同事件回放试验。来源 NaBUru38，CC BY-SA 4.0，公开 SHA-1/大小与下载字节匹配，本地 SHA-256 用于后续基线复核。两段是同一回放机制的不同素材，不新增风格数量；原作者无背书。

样帧可见助跑、腾空、落垫及后续；第一段后续出现旗帜信号，未认证其正式判定。文件名、显示牌及单帧姿态均未用于声称胜负、成绩、人物身份或进步。原事件全段保留，初版回放随后延长到源片结尾；两次局部修订保留原作品版本链。手机控制栏遮住底部标签的失败截图保留，后续改到已观察的上方背景。

证据只能支持已检查的映射、运行、局部画面与浏览器行为。连续运动理解、听检、官方结果、事件召回、独立风格效果和原生编辑器验收分别保持未完成。
