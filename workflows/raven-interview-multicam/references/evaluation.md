# 访谈多机位评测

风格卡是待验证的设计，不计入效果通过。按素材家族划分开发与留出，不能用同一次采访的不同段伪装独立泛化验证。

## 素材条件

逐步覆盖双人、多人/重叠发言、单相机、独立录音、相机中断、长时漂移、远近麦差异、问题不在画面、静默反应及有用户手工编辑的工程。合成媒体验证算术，单源派生模拟验证真实波形算法；两者均不是真实多机位采访验收。

已剪节目母版单列素材类别：可以证明节选和上下文保护，不能计入原始机位同步验收。短答增加跨话轮的后文限制检查；用删除限制的负例确认保护约束实际生效，再对完整成片看听确认语义。Royal Society访谈开发候选见 `evals/runs/cloke-interview-trials-01/`；其中ASR全文REVIEW_REQUIRED，不使用未经校准的对话字幕。

## 一组可复核交付

保存原始 Query、授权来源与源哈希、事件对应证据、测量请求/回执、同步母版、逐词稿来源、导演决定、风格版本、可编辑作品版本、实际输出及最终评审。每段导演决定说明哪个问题/回答成立、为何选这个镜头；不要求暴露内部推理过程。

| 检查 | 观察证据 | 失败例 |
|---|---|---|
| 同一时刻 | 早中晚实际事件及嘴型；测量误差与未测范围 | 共享片头对齐而正文不同步 |
| 观点归属 | 对照源话轮、否定/限定/修正、问题上下文 | 把主持人引用剪成嘉宾主张 |
| 连续声音 | 完整听检，重点切机位和删减接点；检查串音与截字 | 画面换了，房间声或音量突然跳变 |
| 反应真实性 | 反应镜头的会话时间与同期发言对应 | 后录点头被用作当时赞同 |
| 空间与可读性 | 完整播放最终合成画面 | 频繁越轴、字幕遮口、重叠发言找不到人 |
| 风格差异 | 同素材对照并指出选段/结构/声画的实际差别 | 仅换字幕字体就算新风格 |
| 修改保护 | 修改前后文档/媒体差异及恢复回读 | 换机位时误删已校对字幕或更换声音 |
| 重叠字幕时序 | 各说话人源/显示窗口、分割输出、回应前/中/后合成帧 | 把短回应与主句合并后提前显示为已回应 |

风格评审同时看目标适配、真实性、可理解性、视听自然度与独特机制。严重歪曲、伪造即时反应或观点归属错误直接失败；观看偏好另记录，不靠总分抵消事实错误。

每种要进入默认推荐的风格须有真实样片与完整看听记录；先在同素材比较，再跨不同人物/场景复验。单人评审明确标记，不能声称独立盲评。缺真实素材、ASR、声音聆听或宿主时继续可验证步骤，相关结论保留 NOT_RUN。

重叠字幕修复案例见 `evals/runs/interview-overlap-repair-01/`。区间分割验证不能证明源对齐准确，逐帧活跃文本一致也不能证明读屏和声音自然。保留原字幕及原报告，通过新结果明确替代，不把修订后的字幕重新命名为独立素材或新风格。
