# 正式发言、外部原稿与烧录字幕

用于已有真人发言、来源日期、外部文字稿或屏内字幕的编辑。先识别用户是要完整留档、专题节选还是行动分工，不把所有发言压成同一种“观点短视频”。风格见[完整留档](../../../styles/speech/complete-record.md)、[问题与应对专题](../../../styles/speech/issue-context.md)、[行动主体清单](../../../styles/speech/actor-action.md)。

## 四种内容身份

1. 外部文字稿：保留发布页、修订号、原文、取得时的哈希和适用范围。官方或配套稿可以支持文字核对，不证明每个字实际被说出。
2. ASR稿：保留识别原始文字和模型时间。结构可导出仍可能有词义错误，不用它覆盖已有源字幕。
3. 屏内字幕：源视频中的像素内容。OCR是观察，必须能回到帧图、PTS和裁切范围；OCR结果不等于已经人工校对。
4. 实际声音：是否说出、是否吞字、气口与自然切点须另验。前三者相符不能冒称已完成听检。

文字有差异时记录比较和证据；更正稿另建版本。不能把外部文本贴到旧ASR时间上，也不能把包含完整句子的一个单元伪装成“一个词”来绕过逐词合同。

## 段落与细剪分开执行

有明确源范围的段落节选可以直接形成ExecutionPlan，登记为同一作品并派生版本；不必为了调用speech-plan-compile制造逐词时间。此路径保留范围及内容依据，明确声学未验证项，供可审阅试剪。需要删句内词、重录take选择或改变词级接点时，再满足逐词合同与实际边界复核。

每个段落写清：原问题、发言主体、行为对象、状态（建议/要求/已做/将做）、否定和条件、独立可理解性、删去的背景。正式发言的原文立场保持为来源陈述，不由编辑改写成已认证事实；历史日期与节选身份不能抹掉。

## 烧录字幕影响切点

段落声音前的安静区可能仍显示上一段字幕。在那里直接切入，会把不属于新段落的文字带入。核对源字幕切换前后帧，并与声音范围分别记录；切到字幕切换点不能自动证明声音安全。

若声音与字幕边界冲突，优先保留足够完整的上下文、寻找无字幕母版或按已授权方式修复字幕；不偷偷裁掉字幕区、遮盖原字幕或切断首音。可用时机不足的候选应标明问题，不能仅因黑帧/静音检查通过而接受。

新增标签要说明来源日期、专题与节选身份，避免遮挡原日期、原字幕、人物表情及手势。需要只改标签时，冻结画面范围、音频、风格、其他字幕和父版，在同一作品提交，重新导出并检查差异。

## 实际发现与限制

该素材是准备好的政治正式发言，作为中性保真试剪样本，不能代替即兴知识讲解、方言、重录或重叠对白验收。范围外的素材需要另测；不把这一个样本扩张成所有口播的固定余量或配方。
