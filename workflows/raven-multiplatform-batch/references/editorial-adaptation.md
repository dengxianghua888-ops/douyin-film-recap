# 从相同核心到不同表达

先列事实、命题、动作关系与必要上下文，再根据每版的任务决定组织方式。主题拆条保留问题或补真实的最小背景；答案不能变独立承诺，比较不能丢参照物，演示不能只留结果而丢适用条件。会议里的个人意见不改团队决议；剧情短版不因删铺垫改变因果；产品短版不制造性能证明。

同一素材可有：保全过程的教学版、提问—回答的问答版、前提—结果的短证据版、结果先行的概览版。每版的省略清单记录源区间、作用、理由和仍需保留的关联；不能为达时长只选“最刺激”的孤立句。无声阅读版保留必要文字信息，但不能仅把音量归零就声称可无声理解。

风格组合选择一个主要组织机制与需要的呈现策略，遇到冲突以用户保护项和内容真实为先。不同钩子的试验尽量仅改变待测维度，保留其余共因；成片有差异不证明传播效果提升，没有真实观众数据不报告转化增益。
