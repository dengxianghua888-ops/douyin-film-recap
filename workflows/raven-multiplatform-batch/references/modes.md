# 模式与路由

“横版转竖版，内容别变”只授权空间／排版适配；不自动加钩子、删片段、提速或重新配音。“剪成30秒故事版”需要内容判断，时长只是约束。“帮我导出这三个已确定版本”仅队列，不重新选择风格。“做英语版”由本地化决定文本／声音，批量机制仅管理不同版状态。只有一个明确裁切矩形时直接原子执行即可。

ANALYZE／PLAN止于所求分析／方案，不写作品或建导出队列。EDITABLE按当前来源和修订交可继续修改的完整候选、差异与父子对应；未授权采用/导出时止于候选，不把JSON计划冒充已验原生工程。REVISION先读各目标最新状态，只改授权对象并保父版/兄弟版；小样只做指定区间。PRODUCE完成所求实际文件与相应验证；仅格式转换不擅加叙事，纯字幕目标只核文本/对象读回，不制造音视频制作。平台规则来自用户规格或当前可核官方信息，记录核对日期；没有信息时写成自定试验profile，不声称某平台通用标准。不要预设所有短视频更快、每个平台都必须内容不同。
