# 同一作品的版本家族

版本清单逐项记录稳定版本ID、实际父作品/父修订和祖先关系、用途／受众、语种、目标画布/fps/时长/声音、共享事实／主题／品牌规则、继承项、允许覆盖项、保护的手工编辑、需要重新验收项、实际输出位置或对象ID及执行状态。按所选工具绑定可核身份：可读文件用哈希，编辑器对象可用稳定ID加作品/修订并明示字节哈希未知；不得为凑字段伪造摘要或迁入SQLite。parent_work/version/document_hash是本库本地Work的字段，选择该实现或明确字节冻结时仍满足其严格合同。来源、主题和修改谱系共享；每版当前状态独立，禁止以复制最终视频或重命名冒充可编辑版本。

变更先定位作用域：父版事实纠错应列出受影响后代并逐版重新比对；某一版字号或钩子修订不推给所有兄弟版。当前实现记录祖先链，不自动合并未来父版改动，不解决跨NLE协同。用最新子版作为后续编辑基准；旧批次固定的是历史版本，不拿成功旧输出冒充新人工修订。

scope要覆盖实际受影响对象，而不是宽泛all。画布变化影响全部画面；换源影响相关字幕／音轨与检查状态；删段或重排影响时间锚点。执行层复核actualDiff，创作层复核删段是否改变意义，两者互不替代。父版和兄弟版当前状态、未授权文字／声音／主风格在回读中均须保持。
