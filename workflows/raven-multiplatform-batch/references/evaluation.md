# 每版验收与家族验收

按本次模式验收。技术身份遵循通用能力交接：可读文件用哈希，编辑器对象用实际稳定ID/作品修订并明示字节未知；选择本地严格操作或明确字节冻结仍须满足对应合同。核实际涉及的父子谱系、来源／工具／回执、作用域及父版/兄弟版保持。ANALYZE/PLAN核依据与判断；EDITABLE核候选、来源/修订、差异和实际可继续修改性，不要求先渲染。成片才核实际画幅/帧钟/时长、涉及的字幕/完整声音、输出读回及看听；纯文本字幕按文本目标核，不制造媒体检查。库级批量恢复验证仍需至少一项实际失败、其他项成功、恢复只新增必要失败项尝试、成功项身份及尝试不变、当前手改不被历史覆盖；正常交付不人为制造失败或真人事件，D6/G5另验。

内容：发生内容改编的版本应有独立可理解的开头、关系、必要限定与结尾；删改记录能解释为何没有改变事实。完整换格式按所求保留范围核对，不为凑叙事结构擅改原内容；原片未决或片段边界仍准确保留。相同比例不证明相同意义，不同画幅也不证明有独特风格。每个目标画面复查文字／署名、安全区、人物／动作关系与不允许的裁切。

效果：同素材不同表达做对照，记录选择差异和反例；完整看听、目标屏幕阅读、独立受众效果与自然语言留出路由分别报告。抽帧、HTTP200、解码测试、SKILL格式检查都不能代替这些。当前本地SQLite并非原生编辑器可回编辑往返证明；仅明确承诺目标编辑器原生工程时追加对应打开、修改、导出和重开证据。普通交付按本次产物汇总，技术DEGRADED/未认证标记仍保留原回执，独立效果、真人同作与库级发布不由此授予。动态跟踪、平台上传、远端并发和跨语言能力按当前Agent实际工具及本次声明分别核验；缺证据保持未证，不把本库本地未实现泛化为所有工具不可用。
