# 影视解说创作与接管协议

协议版本：film-recap-content/1。权威来源为 douyin-film-recap 的本文件；ChatCut 包携带同版本副本以便独立使用。执行工具与运行目录由各自入口定义。

## 创作意图

从用户请求确定内容单位（一个高光、一条人物/关系线、单集、全片或系列 Part）和交付对象。记录核心问题、观众前置知识、叙述立场、剧透边界、时长、必须保留的声音与情绪落点。未给出的普通偏好可合理推断并标明；用户明确的设置优先。

快节奏以状态变化衡量，不以固定秒数或剪切次数衡量。原片比例、钩子时限和段落数都是题材与篇幅的建议，不能压过一句台词、一个动作或一次反应的必要完整性。

## 证据与四条时间轴

区分源素材时间、故事发生顺序、原片信息揭示顺序、成片时间。事实、强推断和弱推断分开；人物说的话不一定是真相。每条关键因果、身份与关系判断至少关联源素材时间或用户明确上下文，无法确认时使用稳定临时称呼。

每个开头候选都检查前情依赖和可前置资格。禁止把无效候选、最高分排序或未知身份当作绕过剧透约束的理由；若用户明确授权结果前置，记录授权策略、原因与实际使用的事件。

## 高光与视听分工

高光可来自冲突、反击、动作、台词、表演、情绪、揭示、悬念、喜剧、奇观、人物选择、关系变化与道德代价。选取时回答：观众看得懂吗、删掉损失什么、最小完整过程在哪里、是否需要原声。无需每条作品凑齐所有类型。

VO 负责背景、跨时空、重复过程压缩、必要因果桥；原片负责无法被复述替代的表演和视听过程。不要用 VO 预告下一段最强台词，不把反击只剪成结果，不把沉默自动当成无效空白。

每段画面标明用途：直接举证、上下文、反应或转场。使用已看过/分析过的候选范围；关键画面需复查实际选中内容，不能只依赖自己写的镜头描述。

## 可修改的同一份作品

本次任务记录应能串起：关键事实/高光 → 源素材范围 → Beat → 成片片段 → 选择原因。项目素材 ID、任务 ID 与临时时间码仅属于当前作品，不进入通用 Skill。

用户改主线、换开头、替换高光、改一句旁白或切点时，更新该局部及必要依赖。每批编辑前读取当前受影响内容；保留用户已经手动调整的部分，不能用旧方案覆盖最新作品。无法自动解决的意图冲突才需要澄清。

配音/生成按段记录输入、任务状态、返回资产和真实时长。超时后先核对已有任务，再决定是否重试；只重做变化段。现有范围内的生成授权可复用，不逐段重复询问。

## 验收与边界

分别记录结构与媒体规格、内容事实、最终画面、实际声音的检查方法和范围。原片截图不证明合成字幕/构图正确，文件存在不证明听检完成。声明需有来源，未检查到的内容保留未验证状态。

模型意见是待核实线索；能够定位到违反已确定事实/约束的错误才作为阻断证据。审美建议不能冒充确定性错误。

修复最多两轮：初检 → 修复1 → 复检 → 修复2 → 最终复检。最终复检仍失败只报告，不再自动修改第三轮。检查范围跟随改动依赖，避免每个切点都重跑全片。

交付对象决定完成条件：分析不要求配音；可编辑时间线不必默认导出；用户明确要文件时需等待真实导出、回读并给出可用文件。禁止把提交成功、模型自评或局部预览写成全任务已完成。
