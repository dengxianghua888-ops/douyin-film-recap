# 质量门禁（v0.2）

## 三类判断

- 客观：素材身份、时间范围、音视频流、帧率/编码/尺寸/时长、字幕产物、输出指纹，可按可验证规则阻断。
- 语义：人物、事实、因果、反转、揭示顺序与 VO/画面一致性。模型发现是线索，回源交叉验证；明确违反已确定剧透约束可阻断。
- 审美：高光、留白、节奏、声音分工、余味与表达。保留评价和建议，单次主观意见不直接硬阻断。

## 状态与证据

PASSED：该阶段/交付对象的必要检查通过，记录与当前产物一致。完整成片同时要求有效的独立画面与听检记录。

DEGRADED：可供审阅，但能力降级、语义/视听验证缺失或仍有非阻断问题。明确列出未验证范围，不能写作发布认证。

BLOCKED：客观或可核实的契约错误阻断继续交付。保留阶段状态和最后有效产物；不能跳过 pre_qc/post_qc 取得 MP4 后宣称成功。

每项报告保留方法、已检查范围、证据、结果与风险；coverage 不等于 finding 列表为空。实例格式见 [独立复核模板](../examples/review_evidence.example.json)；模板禁止直接当实际通过记录。

## 渲染前

- Manifest 与 Storyboard 源 ID、路径、指纹和时长一致。
- 时间合法、范围有效、引用存在；普通配画能回到分析单元。
- 钩子真实且满足可前置资格，用户明确允许剧透的覆盖必须可追溯。
- 画面覆盖完整 VO；可靠对白边界；原声文本不凭空生成。
- 同源复用明确，规划与 QC 使用相同的题材/用户约束。
- 原声字幕源时间可靠，不把估算词界作为安全切点。
- 语义复核检查事实、因果、揭示及画面用途；缺少语义检查时明确降级。

## 渲染后

自动核对最终文件存在、可探测、音视频流、尺寸、时长、fps、codec、字幕存在与时间范围、要求烧录时的执行记录、黑帧和异常静音。编码配置名需映射到 ffprobe codec 名，如 libx264 → h264。

实际消费镜头与 EDL 一致，原声字幕按源时间换算到成片时间，不能用整段字数分摊替代。无对白段允许没有台词字幕，但其无对白依据必须明确。

独立复核最终合成画面和声音，覆盖用户目标要求的区间并绑定 final SHA256。缺失、过期或覆盖不完整时不 PASSED。自动黑帧/静音检测不等于实际看过/听过，也不能自动证明构图、字幕视觉或原声情绪正确。

## 修复与恢复

初检 → 修复1 → 复检 → 修复2 → 最终复检。最后仍失败只报告，最多两轮修改。修改局部只重做受影响依赖；上游实际重算后，下游 QC 与交付不得继续引用旧版本。

本地自动修复目前针对有限的可重建渲染错误。人物/因果、剧透、字幕视觉、表演与审美问题由 Agent 回源处理，不能通过同输入重复渲染假装修复。

## 报告

交付模式、文件/版本、计划与实际时长、声音比例、高光、模型服务、每类检查方法/范围、未执行/失败/降级项，以及可接管入口。独立记录是具名声明，不是程序能证明其主观评价一定正确。
